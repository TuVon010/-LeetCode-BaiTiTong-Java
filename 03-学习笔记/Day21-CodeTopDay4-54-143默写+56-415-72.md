## 二、逐题笔记

### 0. 开场默写：54 螺旋矩阵 ✅

K神写法（while(true) + 每方向后判断）：
```java
int top=0, bottom=matrix.length-1, left=0, right=matrix[0].length-1;
Integer[] res = new Integer[(bottom+1)*(right+1)];
int k = 0;
while (true) {
    for (int i=left; i<=right; i++) res[k++] = matrix[top][i];
    if (++top > bottom) break;
    for (int i=top; i<=bottom; i++) res[k++] = matrix[i][right];
    if (--right < left) break;
    for (int i=right; i>=left; i--) res[k++] = matrix[bottom][i];
    if (--bottom < top) break;
    for (int i=bottom; i>=top; i--) res[k++] = matrix[i][left];
    if (++left > right) break;
}
return Arrays.asList(res);
```

**昨天 5 个错误今天全避：** 函数名拼写、Integer[]+Arrays.asList、行列索引、top/bottom命名、收缩边界

**知识点：**
- 可以直接用 `ArrayList<Integer>` 收集（不用预分配 Integer[]），更简单
- `new int[res.size()][]` 指定 toArray 返回类型
- 二维数组创建必须指定第一维尺寸

### 2. 快速复习要点

**236 纠正：** 判断的是递归返回值 `left`/`right`（找没找到），不是树结构 `root.left`/`root.right`（有没有孩子）

**300 纠正：** dp[i] 必须是"**以 nums[i] 结尾**的最长递增子序列长度"，不是"到当前位置"。为什么只检查 nums[j]<nums[i]：dp[j] 已保证以 nums[j] 结尾的子序列递增，只需最后一步 nums[j]<nums[i]

### 3. 56 合并区间 🟡

**思路：** 按起点排序 + 贪心扫描合并

**今日 3 个错误：**
| 错误 | 纠正 |
|------|------|
| 合并时终点直接赋值 `= interval[1]` | 取 max：`Math.max(last[1], interval[1])` |
| `return merge.toArray()` 返回 Object[] | `return res.toArray(new int[res.size()][])` |
| `merge.add(interval)` 直接加引用 | 建议 `new int[]{interval[0], interval[1]}` |

**toArray 知识点：**
- 无参 toArray() 因泛型擦除返回 Object[]
- 有参 toArray(T[] a) 通过传入数组指定返回类型
- `new int[res.size()][]` 第一维指定大小，第二维留空
- 二维数组创建必须指定第一维尺寸

**正确代码：**
```java
Arrays.sort(intervals, (a,b)->a[0]-b[0]);
List<int[]> res = new ArrayList<>();
for (int[] interval : intervals) {
    if (res.isEmpty() || interval[0] > res.get(res.size()-1)[1]) {
        res.add(new int[]{interval[0], interval[1]});
    } else {
        res.get(res.size()-1)[1] = Math.max(res.get(res.size()-1)[1], interval[1]);
    }
}
return res.toArray(new int[res.size()][]);
```

### 4. 415 字符串相加 ✅

**思路：** 双指针从后往前 + 进位 carry + StringBuilder 逆序

**今日唯一错误：** 循环条件缺少 `carry > 0`（99+1 时最高位进位漏掉）

**正确代码：**
```java
int i = num1.length()-1, j = num2.length()-1, carry = 0;
StringBuilder sb = new StringBuilder();
while (i >= 0 || j >= 0 || carry > 0) {
    int n1 = i >= 0 ? num1.charAt(i)-'0' : 0;
    int n2 = j >= 0 ? num2.charAt(j)-'0' : 0;
    int sum = n1 + n2 + carry;
    carry = sum / 10;
    sb.append(sum % 10);
    i--; j--;
}
return sb.reverse().toString();
```

**知识点：**
- charAt(i) 取字符，`c - '0'` 转数字
- 越界当 0 处理
- StringBuilder 自带 reverse() 方法
- `new StringBuilder()` 和 `new StringBuilder("")` 等价

### 5. 72 编辑距离 🟡

**思路：** 双串 DP，dp[i][j] = word1 前 i 个转 word2 前 j 个的最少操作数

**三种操作对应关系（核心理解）：**
| 操作 | 最后一步干什么 | 谁被处理了 | 剩下的子问题 | 状态转移 |
|------|--------------|-----------|------------|---------|
| 替换 | word1[i] 换成 word2[j] | i 和 j 都匹配了 | 前 i-1 转前 j-1 | `dp[i-1][j-1]+1` |
| 删除 | 删掉 word1[i] | i 被删了 | 前 i-1 转前 j | `dp[i-1][j]+1` |
| 插入 | 插入匹配 word2[j] | j 被匹配了 | 前 i 转前 j-1 | `dp[i][j-1]+1` |

**口诀：替换两个都少，删 word1 少 i，插 word2 少 j。**

**正确代码：**
```java
int m = word1.length(), n = word2.length();
int[][] dp = new int[m+1][n+1];
for (int i=0; i<=m; i++) dp[i][0] = i;
for (int j=0; j<=n; j++) dp[0][j] = j;
for (int i=1; i<=m; i++) {
    for (int j=1; j<=n; j++) {
        if (word1.charAt(i-1) == word2.charAt(j-1)) {
            dp[i][j] = dp[i-1][j-1];
        } else {
            dp[i][j] = 1 + Math.min(dp[i-1][j-1], Math.min(dp[i-1][j], dp[i][j-1]));
        }
    }
}
return dp[m][n];
```
