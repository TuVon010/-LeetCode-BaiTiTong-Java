## 一、今日模板回顾

### 异或找唯一
```java
int res = 0;
for (int num : nums) {
    res ^= num;
}
return res;
```

### 摩尔投票法（找众数）
```java
int candidate = nums[0], count = 1;
for (int i = 1; i < nums.length; i++) {
    int num = nums[i];
    if (count == 0) {
        candidate = num;
        count = 1;
    } else if (num == candidate) {
        count++;
    } else {
        count--;
    }
}
return candidate;
```

### 荷兰国旗（三指针）
```java
int p0 = 0, cur = 0, p2 = nums.length - 1;
while (cur <= p2) {                    // 到 p2 就停（p2 右边全是 2）
    if (nums[cur] == 0) {
        swap(nums, p0, cur);
        p0++;
        cur++;                         // 换来的必是 1 或 0，可前进
    } else if (nums[cur] == 2) {
        swap(nums, p2, cur);
        p2--;                          // ⭐ cur 不动！换来的未看过，重查
    } else {
        cur++;                         // 是 1，直接走
    }
}
```

## 二、做题记录

### 1. 只出现一次的数字（Easy · 136）
- **核心思路：** 全部异或。成对的数 `a^a=0` 抵消，唯一数 `a^0=a` 留下。
- **代码实现：**
  ```java
  public int singleNumber(int[] nums) {
      int res = 0;
      for (int num : nums) res ^= num;
      return res;
  }
  ```
- **复杂度：** O(n) / O(1)
- **掌握程度：** 🟡（REV-80）
- **感悟/易错点：** 异或三件套：`a^0=a`、`a^a=0`、交换律结合律；位运算优先级比 `==` 低要加括号。

### 2. 多数元素（Easy · 169）
- **核心思路：** 摩尔投票「打擂台」——不同元素互相抵消（count--），count 归零就换候选人。众数 > n/2 必定笑到最后。
- **代码实现：**
  ```java
  public int majorityElement(int[] nums) {
      int res = nums[0];
      int count = 0;
      for (int num : nums) {
          if (count == 0) res = num;
          if (res == num) count++;
          if (num != res) count--;
      }
      return res;
  }
  ```
- **复杂度：** O(n) / O(1)
- **掌握程度：** 🟡（REV-81）
- **感悟/易错点：** 先判 `count==0` 换人，再统一结算；用 `if` 而非 `else if` 时注意顺序。

### 3. 颜色分类（Medium · 75）
- **核心思路：** 荷兰国旗三指针。`left` 是 0 区右边界，`right` 是 2 区左边界，`i` 扫描中间。遇 0 换到左并双推进；遇 2 换到右但 **i 不动**（换来的没看过，重查）；遇 1 直接走。
- **代码实现：**
  ```java
  public void sortColors(int[] nums) {
      int left = 0, i = 0, right = nums.length - 1;
      while (i <= right) {
          if (nums[i] == 0) { swap(nums, left, i); left++; i++; }
          else if (nums[i] == 2) { swap(nums, right, i); right--; }
          else { i++; }
      }
  }
  ```
- **复杂度：** O(n) / O(1)
- **掌握程度：** 🟡（REV-82）
- **感悟/易错点：** ⭐ 遇 2 时 `i` 不能 `++`，否则跳过刚换来的值（反例 `[1,2,0]`）；`while(i<=right)` 到 right 就停。

### 4. 下一个排列（Medium · 31）
- **核心思路：** 四步法。①从右往左找第一个升序对 `nums[i] < nums[i+1]`；②从右往左找第一个比 `nums[i]` 大的 `nums[j]`；③交换；④翻转 `i+1` 到末尾。全降序时直接整体翻转。
- **代码实现：**
  ```java
  int i = n - 2;
  while (i >= 0 && nums[i] >= nums[i + 1]) i--;
  if (i >= 0) {
      int j = n - 1;
      while (j >= 0 && nums[j] <= nums[i]) j--;
      swap(nums, i, j);
  }
  reverse(nums, i + 1, n - 1);
  ```
- **复杂度：** O(n) / O(1)
- **掌握程度：** 🟡（REV-83）
- **感悟/易错点：** 找降序用 `>=`（跳过相等的，才能保证「升序对」）；第二步用 `<=`。

### 5. 寻找重复数（Medium · 287）
- **核心思路：** Floyd 判圈。数组当下标链表：`nums[i]` 是下一个节点的下标。有重复数 = 有环，**环入口 = 重复数**。快慢指针相遇 → 慢指针回头 → 再次相遇即环入口。
- **代码实现：**
  ```java
  int slow = nums[0];
  int fast = nums[nums[0]];
  while (fast != slow) { slow = nums[slow]; fast = nums[nums[fast]]; }
  fast = 0;
  while (fast != slow) { slow = nums[slow]; fast = nums[fast]; }
  return slow;
  ```
- **复杂度：** O(n) / O(1)
- **掌握程度：** 🟡（REV-84）
- **感悟/易错点：** 起点都从 `nums[0]` 出发（0 不可能是环入口，因为值域 1~n）；第一阶段快指针走两步 `nums[nums[fast]]`。
