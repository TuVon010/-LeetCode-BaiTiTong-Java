## 二、做题记录

### 1. 合并两个有序链表（Easy · 21）· 复训通过

**掌握程度：🟡（迭代版独立写出✅；递归版理解"漏 return"bug）**

- **迭代版（尾插 + 虚拟头）：** dummy 头 + 双指针取小者接上 + 剩尾巴整体接。`cur.next=xxx; cur=cur.next;` 是**尾插法**（维持顺序），不是头插法（头插用于反转）。
- **递归版易错点：** `l1.val < l2.val` 分支里**必须 `return l1`**。漏 return → 继续执行 l2 分支 → 两链指针互相纠缠 → 无限递归栈溢出。
- **三句话：** 头是更小的那个 → 剩下的交给递归 → **return 那个更小的**。

### 2. 二叉树的层序遍历（Medium · 102）· ERR-018 全避

**掌握程度：🟡（骨架下完成，三个坑全避开）**

- ✅ 用 `ArrayDeque` 不是 `ArrayList`
- ✅ 先固定 `int length = queue.size()`（for 里直接 queue.size() 会随入队变化）
- ✅ 用 `poll()` 弹队首（不是 peekFirst）
- 学员自注释三坑：返回格式匹配 / 泛型写法 `Deque<TreeNode>` / 类型匹配

### 3. 岛屿数量（Medium · 200）· 沉岛法

**掌握程度：🟡（核心思路独立，方向笔误修正）**

- 外层遍历找 `'1'` → dfs 沉岛 → count++
- dfs 四件套：①越界返回 ②是水/已标记返回（剪枝）③`grid[row][col]='0'` 沉岛 ④四方向扩散
- **易错：** 方向扩散四行易笔误——本次 `row+1.col`（逗号变句点）+ 缺 `col+1` 重复 `col-1`
- **两种程序模式：** 写死测试用例（本地/面试手撕）vs ACM（Scanner 读输入）

### 4. 搜索旋转排序数组（Medium · 33）· REV-57 复训

**掌握程度：🟡（参考框架后写出，边界 bug 修复）**

- **核心口诀：** "哪半有序看左端点，target 在有序半的值范围 → 去那半"
- **三步走：** ①判哪半有序 `nums[left] <= nums[mid]` ②判 target 在不在有序半值范围 ③决定去留
- **三大翻车点（本次全踩）：**
  - `return nums[mid]` 应为 `return mid`（返回下标不是值）
  - 4 分支写成"无条件去左/去右" = 普通二分，旋转数组失效（反例 target=1, mid=7 时 1 却在右半）
  - 判有序用 `<` 会漏 `left==mid` 退化情况 → 边界 bug（反例 `[2,1]` target=1 返回 -1）；必须 `<=`

## 三、程序骨架专题（学员主动要求补课）⭐

### main 方法签名拆解
```
public static void main(String[] args)
公开的 → 静态的（不用 new）→ 不返回 → 叫 main（JVM 约定入口）→ 接命令行参数
```
`String[] args` = 命令行参数数组（JVM 规矩必须写，刷题时纯占位）

### 三种模式对比
| 模式 | 写什么 | 要不要 main |
|------|--------|-----------|
| LeetCode OJ | `class Solution { 方法 }` | ❌ |
| 本地调试 | Solution + 自己写 main 造数据 | ✅ |
| ACM 笔试 | `class Main { main 读输入+输出 }` | ✅ |

### ACM 输入套路
```java
Scanner sc = new Scanner(System.in);
int a = sc.nextInt();     // 读整数（不吞换行）
String s = sc.next();     // 读单词（遇空格停）
String line = sc.nextLine(); // 读整行
```
⭐ **数字后面要清场：** `nextInt()` 后必须 `sc.nextLine()` 吃残留换行，否则读到空串
⭐ 读二维 char：每行 `String line` → `line.toCharArray()`
