### 2. 合并两个有序数组（Easy · 88）· 新题 🟡

**掌握程度：🟡（第一次写犯 4 个错误，改错后通过）**

**核心思路：** 从后往前填（三指针），因为 nums1 末尾是 0 空位，从后往前填不会覆盖未处理的有效元素。

**第一次犯的 4 个错误：**

| # | 错误 | 正确写法 | 后果 |
|---|------|---------|------|
| 1 | `if (m-n==0)` 特殊判断后直接复制 nums2 到 nums1 前面 | 整块删掉，m==n 是正常情况 | 覆盖 nums1 有效元素（反例 [1,2,0,0]+[3,4] → [3,4,0,0]，正确 [1,2,3,4]）|
| 2 | `while (p1 > 0 && p2 > 0)` | `>= 0` | 漏掉下标 0 的元素（ERR-025 同族复发）|
| 3 | `nums1[k] = nums2[p1]` | `nums1[p1]` | 取错值/数组越界（p1 是 nums1 指针）|
| 4 | 收尾 `while (p1 > 0)` / `while (p2 > 0)` | `>= 0`，且 p1 有剩余不用处理 | 同错误 2 |

**正确版本：**
```java
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int p1 = m - 1, p2 = n - 1, k = m + n - 1;
    while (p1 >= 0 && p2 >= 0) {
        if (nums1[p1] >= nums2[p2]) {
            nums1[k--] = nums1[p1--];
        } else {
            nums1[k--] = nums2[p2--];
        }
    }
    while (p2 >= 0) nums1[k--] = nums2[p2--];
    // p1 有剩余不用管，本来就在 nums1 前面正确位置
}
```
