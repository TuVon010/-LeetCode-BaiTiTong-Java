## 二、今日问题记录

### 1. 124 负贡献取 0（连续犯两次 ⚠️）

**错误代码：**
```java
int left = maxGain(node.left);    // ❌ 没有 Math.max(0, ...)
int right = maxGain(node.right);  // ❌
```

**正确代码：**
```java
int left = Math.max(0, maxGain(node.left));   // ✅ 负贡献取 0
int right = Math.max(0, maxGain(node.right)); // ✅
```

**例子：**
```
    2
   / \
 -1   3
```
不取 0：双臂路径和 = -1+3+2 = 4 ❌
取 0：双臂路径和 = 0+3+2 = 5 ✅

**核心逻辑：** 某个方向单臂路径和为负数，走这个方向会"亏本"，不如不走（取 0）。

**状态：** 连续犯两次，明天默写必须写对，否则继续 🟡。

### 2. 93 复原 IP 地址（未脱离题解 ⚠️）

**问题：**
1. 第二层循环条件写错：`i < n` 应为 `j < n`
2. 用户自述"看着原本的代码写的，原理理解不够深刻，方法使用记不得"

**三重循环原理：**
- IP 固定 4 段，枚举三个分割点 i、j、k
- 第 1 段 [0,i)，第 2 段 [i,j)，第 3 段 [j,k)，第 4 段 [k,n)
- j = i+1 开始（每段至少 1 个字符），k = j+1 同理
- 循环条件加 isValid 自动剪枝

**方法不熟悉：**
- `s.substring(start, end)`：左闭右开，取 start 到 end-1
- `String.format("%s.%s.%s.%s", a, b, c, d)`：4 个 %s 占位符，按顺序填入
