### 1. 92 反转链表 II · 新题 🟡

**题目：** 反转链表从位置 left 到 right 的节点（位置从 1 开始）

**迭代法（头插法）：**
1. 虚拟头 `dummy.next = head`，从 dummy 出发走 `left-1` 步定位前驱 `pre`
2. `cur = pre.next`（反转起点），`tail = cur`（反转后变尾）
3. 头插法反转 `right-left+1` 个节点：`reverseHead` 初始 null，逐个摘 cur 插到 reverseHead 前
4. 重连：`pre.next = reverseHead`，`tail.next = cur`（原后继）
5. `return dummy.next`

**易错点（第一次写犯了 3 个）：**
- ❌ 定位走了 `left` 步 → 应为 `left-1` 步（位置从 1 开始）
- ❌ `left=1` 时 pre=null 空指针 → 必须 `dummy.next=head`，从 dummy 出发
- ❌ dummy 同时当虚拟头和反转临时头 → 角色冲突，必须分离（dummy 挂 head / reverseHead 做反转）

**递归法：**
- `reverseBetween` 递归缩 left 到 1，然后调用 `reverseN(head, right)`
- `reverseN` 反转前 n 个节点，用 `successor` 记录第 n+1 个节点
- `head.next.next = head`（经典递归反转），`head.next = successor`

**用户状态：** 迭代法还不熟悉，**明天必须默写迭代法**（用户主动要求）

### 2. 300 最长递增子序列 🟡

**DP 定义：** `dp[i]` = 以 nums[i] 结尾的最长递增子序列长度

**转移：** 枚举所有 `j < i`，如果 `nums[j] < nums[i]`，`dp[i] = max(dp[i], dp[j]+1)`

**初始：** `Arrays.fill(dp, 1)`（每个元素自身长度为 1）

**答案：** 全局 `max`（不是 dp[n-1]，最长子序列可能在中间结束）

**为什么不能只看 i-1：** 反例 `[2,5,3,7]`，i=3（值 7）最长是 `[2,3,7]` 接棒 j=2（值 3），不是 j=1（值 5）

**进阶：** 贪心+二分 O(n log n)（tails 数组维护最小末尾值），现在先掌握 O(n²) DP

### 3. 103 锯齿形层序遍历 · 新题 🟡

**题目：** 层序遍历，奇数层右到左，偶数层左到右

**正确写法 1（收集完反转，最直观）：**
```java
boolean reverse = false;
while (!queue.isEmpty()) {
    int size = queue.size();
    List<Integer> path = new ArrayList<>();
    for (int i = 0; i < size; i++) {
        TreeNode cur = queue.poll();
        path.add(cur.val);
        if (cur.left != null) queue.offer(cur.left);
        if (cur.right != null) queue.offer(cur.right);
    }
    if (reverse) Collections.reverse(path);
    res.add(path);
    reverse = !reverse;
}
```

**正确写法 2（LinkedList 头插，高效）：**
```java
LinkedList<Integer> path = new LinkedList<>();
if (reverse) path.addFirst(cur.val);  // 奇数层头插
else path.addLast(cur.val);
```

**❌ 错误写法（改变入队顺序）：**
- 以为"当前层先右后左入队 → 下一层右到左出队"
- **隐含前提：当前层必须左到右出队**
- 当前层右到左出队时，先处理右边节点，孩子整体入队顺序反了
- 非对称树（如 `[1,2,3,4,null,null,5]`）第 2 层出错
- 对称树恰好掩盖 bug（之前验证不充分，抱歉）

**LinkedList vs ArrayDeque：**
- LinkedList 同时实现 List 和 Deque，可直接放 `List<List<Integer>>`，有 O(1) addFirst
- ArrayDeque 只实现 Deque，不是 List，不能直接放 res（需转 ArrayList）
- ArrayList 是 List 但头插 O(n)，不如 reverse

### 4. 236 最近公共祖先 🟡

**解法 1：后序递归法（面试首选）**
```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;  // 左右都有，root 是 LCA
    if (left == null) return right;  // 都在右边
    return left;                      // 都在左边
}
```

**递归意义：** 每个节点返回"以该节点为根的子树中，p 和 q 的 LCA"。只找到 p 返回 p，只找到 q 返回 q，都没找到返回 null，都找到了返回 LCA。

**三种组合：**
| left | right | 含义 | 返回 |
|------|-------|------|------|
| 非空 | 非空 | p/q 分别在左右子树 | root（分叉点）|
| 非空 | null | 都在左子树 | left |
| null | 非空 | 都在右子树 | right |
| null | null | 都没有 | null |

**为什么后序：** 必须先知道左右子树结果，才能判断当前节点是不是 LCA

**解法 2：路径记录法（备选，思路直观）**
- DFS 维护当前路径 path，遇到 p 拷贝到 pathP，遇到 q 拷贝到 pathQ
- 两条路径都找到了就剪枝
- 最后比较 pathP 和 pathQ，找最后一个公共节点
- Java 注意：`pathP.addAll(path)` 深拷贝，不能 `=` 引用赋值

## 三、今日知识盲点记录（后面复习带）

1. **Deque 双角色：** ArrayDeque 既可以当队列（offer/poll/peek）又可以当栈（push/pop/peek），栈顶和队头在 ArrayDeque 中都是头部
2. **Java 取反：** 布尔取反用 `!`，不是 `~`（~ 是整数按位取反）
3. **peek vs peekFirst：** Deque 中 peek() = peekFirst()，都看头部；peekLast() 看尾部
4. **res.add(path) 要不要 new：** 层序遍历每次新建 path 不用 new；回溯题 path 是全局必须 `new ArrayList<>(path)` 拷贝
5. **LinkedList vs ArrayDeque：** LinkedList 是 List+Deque 可直接放 res；ArrayDeque 只是 Deque 不是 List
6. **103 改变入队顺序的 bug：** 只在当前层左到右出队时有效，右到左出队时整体反了
7. **236 递归意义：** 每个节点返回子树中的 LCA，不是"找没找到"
