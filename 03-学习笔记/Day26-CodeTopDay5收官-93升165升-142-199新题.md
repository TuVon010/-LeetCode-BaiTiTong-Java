### ✅ 93 复原 IP 地址（从 🟡 升 ✅）

**默写前口述：**
- `s.substring(i, j)` 是对象调用（s 在前点调用），不是 `substring(s, i, j)` 静态调用
- `Integer.parseInt(str)` 是类调用（Integer 是类名）
- 三重循环三个分割点：i 从 1 开始，j 从 i+1 开始，k 从 j+1 开始（每段至少 1 字符）

**代码：**
```java
class Solution {
    public List<String> restoreIpAddresses(String s) {
        int n = s.length();
        List<String> res = new ArrayList<>();
        for (int i = 1; i < n && isValid(s, 0, i); i++) {
            for (int j = i+1; j < n && isValid(s, i, j); j++) {
                for (int k = j+1; k < n && isValid(s, j, k); k++) {
                    if (isValid(s, k, n)) {
                        res.add(String.format("%s.%s.%s.%s",
                            s.substring(0, i),
                            s.substring(i, j),
                            s.substring(j, k),
                            s.substring(k, n)));
                    }
                }
            }
        }
        return res;
    }
    boolean isValid(String s, int i, int j) {
        if (j-i > 3 || (j-i > 1 && s.charAt(i) == '0')) return false;
        return Integer.parseInt(s.substring(i, j)) <= 255;
    }
}
```

**结果：** 昨天的 `s.substring` 调用方式错误今天修正了，全对，从 🟡 升 ✅。

### ✅ 165 比较版本号（从 🟡 升 ✅）

**默写过程：** 第一次没写完（split 返回数组类型、i/j 定义卡住），用 "1.01" vs "1.001" 具体例子走一遍后理解了，第二次写出完整代码。

**核心理解：**
- `Integer.parseInt("01")` = 1，`Integer.parseInt("001")` = 1，自动忽略前导 0
- 按数字比较，不是按字符串比较（"2" < "10" 按数字，"2" > "10" 按字符串）

**代码：**
```java
class Solution {
    public int compareVersion(String v1, String v2) {
        String[] s1 = v1.split("\\."), s2 = v2.split("\\.");
        int n = s1.length, m = s2.length;
        int i = 0, j = 0;
        while (i < n || j < m) {
            int a = 0, b = 0;
            if (i < n) a = Integer.parseInt(s1[i++]);
            if (j < m) b = Integer.parseInt(s2[j++]);
            if (a != b) return a > b ? 1 : -1;
        }
        return 0;
    }
}
```

**结果：** 全对，从 🟡 升 ✅。

## 三、新题学习

### 🟡 142 环形链表 II（新题）

**题目类型：** 链表 / 快慢指针
**核心要求：** 返回链表开始入环的第一个节点，无环返回 null

**思路（Floyd 判圈算法）：**
1. 快慢指针相遇（和 141 一样）
2. 相遇后 fast 回 head，两个指针同步走（速度都为 1）
3. 再次相遇的位置就是环的入口

**数学原理：** 设 head 到入口距离 a，入口到相遇点 b，相遇点到入口 c。slow 走了 a+b，fast 走了 a+2b+c，fast=2×slow → a=c，所以回 head 后同步走 a 步（等于 c 步）就在入口相遇。

**代码问题（边界 bug）：**
```java
// ❌ 错误写法：内层循环"先走再判断"，会错过入口就是 head 的情况
fast = head;
while (true) {
    fast = fast.next;  // 先走一步
    slow = slow.next;
    if (slow == fast) return slow;  // 再判断
}
```

**反例：** 链表 `1→2→3→1`（head=1 就是环的入口），相遇后 fast=head=1，内层循环先走一步变成 2，返回 2 ❌（应该返回 1）。

**正确写法：**
```java
fast = head;
while (slow != fast) {  // 先判断，不相等再走
    slow = slow.next;
    fast = fast.next;
}
return slow;
```

**结果：** 思路对，边界 bug，标记 🟡，明天默写验证。

### 🟡 199 二叉树的右视图（新题）

**题目类型：** 二叉树 / 层序遍历
**核心要求：** 返回从右侧能看到的节点值（按从上到下顺序）

**两种思路：**
1. **BFS 层序遍历**：每层取最后一个节点（推荐，模板熟悉）
2. **DFS 根→右→左**：每层第一次访问到的节点就是最右边的节点

**代码问题（低级错误）：**
```java
while (queue.isEmpty()) {  // ❌ 写反了！应该是 !queue.isEmpty()
```

队列非空时才循环，写反了导致第一次队列有 root（非空），不满足 `isEmpty()`，直接跳过循环返回空结果。

**正确写法：**
```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int length = queue.size();
            for (int i = 0; i < length; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
                if (i == length - 1) {  // 每层最后一个节点
                    res.add(node.val);
                }
            }
        }
        return res;
    }
}
```

**结果：** 思路对，while 条件写反（低级错误），标记 🟡，明天默写验证。
