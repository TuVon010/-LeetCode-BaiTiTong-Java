## 一、本质理解

**数组的本质是连续内存空间**，支持 O(1) 随机访问，但插入/删除需要 O(n) 移动元素。  
**矩阵是二维数组**，底层也是连续存储（行优先）。

## 二、数组核心技巧

### 1. 前缀和（区间和问题）

```java
// import java.util.*;

public int[] prefixSum(int[] nums) {
    int n = nums.length;
    int[] prefix = new int[n + 1];
    for (int i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + nums[i];
    }
    // 区间 [i, j] 的和 = prefix[j+1] - prefix[i]
    return prefix;
}
```

**适用场景：** 需要频繁计算子数组和 → [[02-Wiki/01-哈希表]] 模板 4

### 2. 差分（区间增减问题）

```java
// import java.util.*;

public int[] difference(int[] nums, int[][] updates) {
    // updates: [[l, r, val], ...]
    int[] diff = new int[nums.length + 1];
    for (int[] upd : updates) {
        int l = upd[0], r = upd[1], val = upd[2];
        diff[l] += val;
        diff[r + 1] -= val;
    }
    // 还原
    for (int i = 0; i < nums.length; i++) {
        diff[i + 1] += diff[i];
        nums[i] += diff[i];
    }
    return nums;
}
```

### 3. 原地操作（空间 O(1)）

**三次翻转法 — 轮转数组：**

```java
// import java.util.*;

public void rotate(int[] nums, int k) {
    k %= nums.length;
    // 整体翻转
    reverse(nums, 0, nums.length - 1);
    // 前 k 个翻转
    reverse(nums, 0, k - 1);
    // 后 n-k 个翻转
    reverse(nums, k, nums.length - 1);
}

private void reverse(int[] nums, int left, int right) {
    while (left < right) {
        int temp = nums[left];
        nums[left] = nums[right];
        nums[right] = temp;
        left++;
        right--;
    }
}
```

**前缀积 + 后缀积 — 除自身以外数组的乘积：**

```java
// import java.util.*;

public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] res = new int[n];
    // 前缀积
    int prefix = 1;
    for (int i = 0; i < n; i++) {
        res[i] = prefix;
        prefix *= nums[i];
    }
    // 乘上后缀积
    int suffix = 1;
    for (int i = n - 1; i >= 0; i--) {
        res[i] *= suffix;
        suffix *= nums[i];
    }
    return res;
}
```

**原地哈希 — 缺失的第一个正数：**

```java
// import java.util.*;

public int firstMissingPositive(int[] nums) {
    int n = nums.length;
    // 把值 x 放到索引 x-1 的位置
    for (int i = 0; i < n; i++) {
        while (1 <= nums[i] && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
            int temp = nums[nums[i] - 1];
            nums[nums[i] - 1] = nums[i];
            nums[i] = temp;
        }
    }
    // 找第一个不匹配的位置
    for (int i = 0; i < n; i++) {
        if (nums[i] != i + 1) {
            return i + 1;
        }
    }
    return n + 1;
}
```

### 4. Kadane 算法（最大子数组和）

```java
// import java.util.*;

public int maxSubArray(int[] nums) {
    int curSum = nums[0], maxSum = nums[0];
    for (int i = 1; i < nums.length; i++) {
        curSum = Math.max(nums[i], curSum + nums[i]);
        maxSum = Math.max(maxSum, curSum);
    }
    return maxSum;
}
```

## 三、矩阵核心技巧

### 1. 螺旋遍历（边界收缩法）

```java
// import java.util.*;

public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;
    
    while (top <= bottom && left <= right) {
        // 向右：左 → 右
        for (int i = left; i <= right; i++) {
            res.add(matrix[top][i]);
        }
        top++;
        
        // 向下：上 → 下
        for (int i = top; i <= bottom; i++) {
            res.add(matrix[i][right]);
        }
        right--;
        
        if (top <= bottom) {
            // 向左：右 → 左
            for (int i = right; i >= left; i--) {
                res.add(matrix[bottom][i]);
            }
            bottom--;
        }
        
        if (left <= right) {
            // 向上：下 → 上
            for (int i = bottom; i >= top; i--) {
                res.add(matrix[i][left]);
            }
            left++;
        }
    }
    
    return res;
}
```

### 2. 旋转图像（转置 + 翻转）

```java
// import java.util.*;

public void rotate(int[][] matrix) {
    int n = matrix.length;
    // 转置
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            int temp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = temp;
        }
    }
    // 每行翻转
    for (int i = 0; i < n; i++) {
        int left = 0, right = n - 1;
        while (left < right) {
            int temp = matrix[i][left];
            matrix[i][left] = matrix[i][right];
            matrix[i][right] = temp;
            left++;
            right--;
        }
    }
}
```

### 3. 矩阵置零（原地标记法）

```java
// import java.util.*;

public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRowZero = false, firstColZero = false;
    
    // 检查第一行
    for (int j = 0; j < n; j++) {
        if (matrix[0][j] == 0) {
            firstRowZero = true;
            break;
        }
    }
    // 检查第一列
    for (int i = 0; i < m; i++) {
        if (matrix[i][0] == 0) {
            firstColZero = true;
            break;
        }
    }
    
    // 用第一行和第一列做标记
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;
                matrix[0][j] = 0;
            }
        }
    }
    
    // 根据标记置零
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                matrix[i][j] = 0;
            }
        }
    }
    
    if (firstRowZero) {
        for (int j = 0; j < n; j++) {
            matrix[0][j] = 0;
        }
    }
    if (firstColZero) {
        for (int i = 0; i < m; i++) {
            matrix[i][0] = 0;
        }
    }
}
```

### 4. 搜索二维矩阵（右上角搜索法）

```java
// import java.util.*;

public boolean searchMatrix(int[][] matrix, int target) {
    if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
        return false;
    }
    int rows = matrix.length, cols = matrix[0].length;
    int row = 0, col = cols - 1;  // 右上角出发
    
    while (row < rows && col >= 0) {
        if (matrix[row][col] == target) {
            return true;
        } else if (matrix[row][col] > target) {
            col--;
        } else {
            row++;
        }
    }
    return false;
}
```

## 五、易错点与技巧

1. **边界条件**：矩阵题中始终注意 `row` 和 `col` 的范围，以及空矩阵的特殊情况
2. **原地操作**：想修改原数组时，先问自己"会不会覆盖还没用的数据"
3. **取模运算**：轮转数组 `k %= nums.length` 处理 k > n 的情况
4. **原地哈希**：用数组本身的索引作为哈希 key，值作为标记，空间 O(1)
