# 06 · 栈与堆

> **来源：** 代码随想录栈与队列专题 + 单调栈模板 + labuladong 堆的讲解  
> **核心价值：** 栈解决"后进先出"场景，堆解决"动态最值"场景

---

## 一、本质理解

- **栈（Stack）：** 受限的线性表，LIFO（后进先出），底层是数组或链表
- **堆（Heap / 优先队列）：** 用数组实现的完全二叉树，自动维护最值
- **单调栈（Monotonic Stack）：** 栈中元素保持单调递增或递减，用于找"下一个更大/更小元素"

```java
for (T item : items) {
    if (/* 需要入栈 */) {
        stack.push(item);
    } else {
        // 出栈处理

    }

```

### 单调栈模板（找下一个更大元素）

```java
// import java.util.*;

public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] res = new int[n];
    Arrays.fill(res, -1);
    Deque<Integer> stack = new ArrayDeque<>();  // 存索引
    
    for (int i = 0; i < n; i++) {
        // 当前元素比栈顶大：找到"下一个更大元素"
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
            int idx = stack.pop();
            res[idx] = nums[i];
        }
        stack.push(i);
    }
    
    return res;
}
```

**单调栈变体：**
- 找下一个更大元素 → 单调递减栈（栈底到栈顶递减）
- 找下一个更小元素 → 单调递增栈（栈底到栈顶递增）
- 找上一个更大元素 → 反向遍历

### 柱状图中最大矩形（单调栈经典应用）

```java
// import java.util.*;

public int largestRectangleArea(int[] heights) {
    Deque<Integer> stack = new ArrayDeque<>();  // 存索引，维护递增栈
    int[] h = new int[heights.length + 2];
    System.arraycopy(heights, 0, h, 1, heights.length);  // 加哨兵
    int maxArea = 0;
    
    for (int i = 0; i < h.length; i++) {
        while (!stack.isEmpty() && h[stack.peek()] > h[i]) {
            int height = h[stack.pop()];
            int width = i - stack.peek() - 1;
            maxArea = Math.max(maxArea, height * width);
        }
        stack.push(i);
    }
    
    return maxArea;
}
```

## 三、堆（优先队列）

### Java 堆操作（PriorityQueue）

```java
// import java.util.*;

// 最小堆（默认）
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
minHeap.offer(val);           // 入堆
int minVal = minHeap.poll();  // 弹出最小值
int peekVal = minHeap.peek(); // 查看最小值（不弹出）

// 大根堆：自定义比较器
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Comparator.reverseOrder());
maxHeap.offer(val);
int maxVal = maxHeap.poll();

// 将数组堆化（逐个入堆 O(n log n)，可优化但 PriorityQueue 不直接支持 heapify）
// 若需 O(n) 建堆，可使用 new PriorityQueue<>(Arrays.asList(arr));

// Top K 最大：用最小堆维护
public int topKLargest(int[] nums, int k) {
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    for (int num : nums) {
        heap.offer(num);
        if (heap.size() > k) {
            heap.poll();
        }
    }
    return heap.peek();  // 第 k 大
}
```

### 经典应用：数据流的中位数（双堆）

```java
// import java.util.*;

class MedianFinder {
    // 大根堆存较小一半
    private PriorityQueue<Integer> small;  // max-heap
    // 小根堆存较大一半
    private PriorityQueue<Integer> large;  // min-heap
    
    public MedianFinder() {
        small = new PriorityQueue<>(Comparator.reverseOrder());
        large = new PriorityQueue<>();
    }
    
    public void addNum(int num) {
        small.offer(num);
        // 确保 small 中所有元素 <= large 中所有元素
        if (!small.isEmpty() && !large.isEmpty() && small.peek() > large.peek()) {
            large.offer(small.poll());
        }
        // 平衡两堆大小
        if (small.size() > large.size() + 1) {
            large.offer(small.poll());
        }
        if (large.size() > small.size()) {
            small.offer(large.poll());
        }
    }
    
    public double findMedian() {
        if (small.size() > large.size()) {
            return small.peek();
        }
        return (small.peek() + large.peek()) / 2.0;
    }
}
```

## 五、易错点与技巧

1. **Java 默认是小根堆**：想要大根堆用 `new PriorityQueue<>(Comparator.reverseOrder())`
2. **单调栈存索引而非值**：因为很多时候需要索引来计算距离或宽度
3. **柱状图加哨兵**：在 heights 两端加 0，避免栈空判断和最后清空栈
4. **Top K 技巧**：求第 K 大用最小堆（堆大小 = K），求前 K 大也一样
5. **堆的时间复杂度**：offer 和 poll 都是 O(log k)，逐个建堆 O(n log n)

## 六、复杂度总结

| 结构 | 操作 | 时间复杂度 | 空间复杂度 |
|------|------|-----------|-----------|
| 栈 | 入栈/出栈 | O(1) | O(n) |
| 单调栈 | 一次遍历 | O(n) | O(n) |
| 堆 | offer/poll | O(log n) | O(n) |
| 堆 | 逐个建堆 | O(n log n) | O(n) |
