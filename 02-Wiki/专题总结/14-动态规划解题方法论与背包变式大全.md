## 一、DP 总纲：什么时候用 DP？

### 1.1 三个特征（同时满足才用 DP）

| 特征 | 一句话 | 反例 |
|------|--------|------|
| 最优子结构 | 大问题的最优解 = 子问题最优解拼起来 | 走迷宫（要全局信息）|
| 重叠子问题 | 同一个子问题被反复计算 | 斐波那契（递归版超时）|
| 无后效性 | 子问题一旦算出，不受后续决策影响 | 股票问题（要加状态维度）|

### 1.2 判断口诀

> 看到"**最长 / 最少 / 最大 / 方案数 / 能不能**" + 能拆成**子问题** + 贪心**有反例** → 上 DP。

### 1.3 DP 五步法（永远的顺序）

```
① dp 数组含义是什么？       ← 最最重要，想不清就全盘皆输
② 状态转移方程是什么？       ← 从小的推大的
③ 怎么初始化（base case）？ ← dp[0] 这种"地基"
④ 遍历顺序？（正/倒，内/外）← 背包题的关键考点
⑤ 手动验证小例子            ← 写代码前先用纸推一遍
```

### 1.4 两种实现

| 方式 | 特点 | 适用 |
|------|------|------|
| 自顶向下（递归 + 记忆化 memo） | 好想、好写、慢一点 | 思维推演（139 递归版）|
| 自底向上（迭代填表） | 难想、快、能空间优化 | 正式代码 |

> ⭐ 思维链（Day 12 反复练的）：**先递归 → 发现重叠子问题 → 记忆化 → 写成迭代（滚动变量）**

## 二、怎么判断"这个题是不是背包"？

### 2.1 背包三件套（同时出现才是背包题）

| 特征 | 例子 |
|------|------|
| ① 有一堆"东西"（每个有重量/值/面额/数） | coins、nums、weights |
| ② 有一个"容量/目标值" | amount、target、capacity |
| ③ 问"能不能 / 最多 / 最少 / 多少种方案" | 能不能凑出、最少几枚、几种方法 |

**例题速判：**

| 题目 | 一堆东西 | 目标值 | 问什么 | 判定 |
|------|---------|--------|--------|------|
| 416 分割等和子集 | 一堆数 | target = sum/2 | 能不能凑 | ✅ 背包 |
| 322 零钱兑换 | 硬币们 | amount | 最少几枚 | ✅ 背包 |
| 279 完全平方数 | 平方数 1,4,9.. | n | 最少几个 | ✅ 背包（平方数也是"东西"！）|
| 300 最长递增子序列 | 一堆数 | 无 | 最长 | ❌ 不是（子序列 DP）|
| 62 不同路径 | 无 | 无 | 路径数 | ❌ 不是（路径 DP）|

### 2.2 分类三问（确定是哪一种背包）

```
Q1: 每个"东西"能用几次？
    ├ 一次   → 0-1 背包（内层倒序）
    └ 无限次 → 完全背包（内层正序）

Q2: 求什么？（决定转移操作）
    ├ 能不能凑出   → boolean + ||     （416）
    ├ 最少几个     → int + min + ∞哨兵（322 / 279）
    ├ 最多/最大价值 → int + max         （经典背包）
    └ 多少种方案   → int + +=          （518 / 377）

Q3: 方案数里，顺序算不算？（决定内外层）
    ├ 顺序无关（组合：1+2 和 2+1 算一种）→ 外层物品
    └ 顺序有关（排列：1+2 和 2+1 算两种）→ 外层容量
```

## 三、一维 DP 四大骨架

### 骨架 A · 斐波那契型（只看前 1-2 个）
- **例题：** 70 爬楼梯
- **特征：** dp[i] 只依赖 dp[i-1]、dp[i-2]
- **转移：** `dp[i] = dp[i-1] + dp[i-2]`
- **优化：** 滚动变量 `ll/last/cur`，每轮 `ll=last; last=cur`

### 骨架 B · 选/不选型（线性）
- **例题：** 198 打家劫舍
- **特征：** 对第 i 个，要么选它、要么不选它
- **转移：** `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
- **优化：** 滚动变量（与 A 同骨架，只差"转移动作"加法 vs 取 max）

### 骨架 C · "以 i 结尾"型（内层枚举）
- **例题：** 300 最长递增子序列
- **特征：** dp[i] = **以 nums[i] 结尾**的最优；要从**前面任意 j** 转移
- **转移：** `dp[i] = max(dp[i], dp[j]+1)` 对 `j < i 且 nums[j] < nums[i]`
- **优化：** 不能简单滚动（要看任意前面）→ 必须数组

### 骨架 D · 双状态型（同时维护两个量）
- **例题：** 152 乘积最大子数组
- **特征：** 只记一个量不够，**负数会翻盘** → 同时维护最大和最小
- **转移：** `curMax = max(curMax*x, curMin*x, x)`；curMin 对称取 min
- **注意：** 必须用 `temp` 存旧值，否则 curMin 算的时候 curMax 已被覆盖

### 对比小结

| 骨架 | 依赖范围 | 能不能滚动 | 代表题 |
|------|---------|-----------|--------|
| A 斐波那契 | 前 1-2 个 | ✅ | 70 |
| B 选/不选 | 前 1-2 个 | ✅ | 198 |
| C 以 i 结尾 | 任意前面 | ❌ 数组 | 300 |
| D 双状态 | 前 1-2 个（两个量） | ✅ | 152 |

> **⭐ 判断标准（重要）：** 状态转移只看前 1-2 个 → 滚动变量；要看**任意前面的** → 数组。

## 四、二维 DP 三大骨架

### 骨架 E · 矩阵路径型
- **例题：** 62 不同路径 / 64 最小路径和
- **特征：** dp[i][j] 从上方 `dp[i-1][j]` 或左方 `dp[i][j-1]` 来
- **转移：** `dp[i][j] = dp[i-1][j] + dp[i][j-1]`（路径数）或 `grid[i][j] + min(...)`（路径和）
- **初始化：** 第一行、第一列先填
- **优化：** `dp[j] = grid[i][j] + min(dp[j], dp[j-1])`（j 从左到右，滚动数组）

### 骨架 F · 双串比较型
- **例题：** 1143 最长公共子序列 / 72 编辑距离
- **特征：** 两个字符串，dp[i][j] = word1 前 i 个 vs word2 前 j 个
- **转移（LCS）：**
  - 相等：`dp[i][j] = dp[i-1][j-1] + 1`
  - 不等：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
- **初始化：** 第 0 行第 0 列
- **优化：** 需要 `pre` 存左上角，再滚动

### 骨架 G · 区间型
- **例题：** 5 最长回文子串
- **特征：** dp[i][j] 表示 s[i..j] 这个**区间**；从短区间推到长区间
- **转移：** `dp[i][j] = s[i]==s[j] && dp[i+1][j-1]`
- **遍历：** 按**区间长度从小到大**（不是普通 i 从 0 到 n！）

## 四·五、降维三问（二维 → 一维的通用套路）⭐⭐

> **本质：** 按行滚动——一次只留「上一行 + 当前行」，算完一行丢一行。二维数组里那些"上上行"算完就再也用不到，滚掉省空间 O(m×n) → O(n)。

### 拿到任何二维 DP，问三句话

```
① 依赖谁？                    （上 / 左 / 左上 / 右下…）
② 按什么方向遍历时，哪个旧值会被覆盖，但后面还需要？
③ 被覆盖又需要的 → 变量暂存；不需要的 → 直接覆盖
```

### 各题对照（一表记全家）

| 题 | 依赖 | 遍历方向 | 被覆盖的关键值 | 解法 |
|----|------|---------|--------------|------|
| 62 路径 | 下、右 | 从右往左 | 无（用完即弃）| `dp[j] += dp[j+1]` |
| 416 0-1背包 | 左 | **倒序** | 左边旧值 | 倒序天然保留旧值 |
| 322 完全背包 | 左 | 正序 | 左边旧值 | 正序=允许复用 |
| 1143 LCS | 上、左、左上 | 左→右 | **左上** | `prev` 暂存 |
| 72 编辑距离 | 上、左、左上 | 左→右 | **左上** | 同 LCS，`prev` 暂存 |

> 416/322 你早就降过维了——`dp[j]` 就是把"物品×容量"二维滚成一维，**倒序/正序**就是保护"左边旧值"的手段。LCS/72 多了一个**左上**，必须用变量 `prev` 手动暂存。

### LCS 滚动代码（`prev` 暂存"左上"）

```java
public int longestCommonSubsequence(String text1, String text2) {
    int n = text1.length(), m = text2.length();
    int[] dp = new int[m + 1];          // 滚动一维，初始全 0 = 第 0 行
    for (int i = 1; i <= n; i++) {
        int prev = 0;                    // 每行开头，prev = dp[i-1][0] = 0
        for (int j = 1; j <= m; j++) {
            int temp = dp[j];            // ① 先抱走 dp[j]（= 上 dp[i-1][j]，下一轮的"左上"）
            if (text1.charAt(i-1) == text2.charAt(j-1)) {
                dp[j] = prev + 1;        // 配对：prev = dp[i-1][j-1]
            } else {
                dp[j] = Math.max(dp[j], dp[j-1]);   // 淘汰：dp[j]=上, dp[j-1]=左
            }
            prev = temp;                 // ② 把刚抱走的旧值交给 prev，供下一轮当"左上"
        }
    }
    return dp[m];
}
```

**三方向的旧值去哪了？**
| 需要的旧值 | 在哪 | 状态 |
|-----------|------|------|
| 上 `dp[i-1][j]` | `dp[j]`（本轮覆盖前）| ✅ 直接用 |
| 左 `dp[i][j-1]` | `dp[j-1]`（刚被本行更新）| ✅ 正好是当前行的左 |
| 左上 `dp[i-1][j-1]` | 曾经的 `dp[j-1]` | ❌ 被"左"覆盖 → `prev` 提前抱走 |

## 五、背包变式对照表 ⭐⭐

| 变式 | 例题 | 类型 | 求什么 | dp 初始化 | 转移核心 | 内层顺序 |
|------|------|------|--------|----------|---------|---------|
| A 子集凑和 | 416 分割等和子集 | 0-1 | 能不能 | `dp[0]=true` | `\|\|` | 倒序 |
| B 最少个数 | 322 零钱 / 279 平方数 | 完全 | 最少 | `fill(∞), dp[0]=0` | `min` | 正序 |
| C 组合方案数 | 518 零钱兑换 II | 完全 | 方案数 | `dp[0]=1` | `+=` | 外层物品·正序 |
| D 排列方案数 | 377 组合总和 IV | 完全 | 方案数 | `dp[0]=1` | `+=` | 外层容量·正序 |
| E 最大价值 | 经典背包 | 0-1/完全 | 最大 | `dp 全 0` | `max` | 倒/正 |

### 变式 A 详解（416 分割等和子集）
```java
boolean[] dp = new boolean[target + 1];
dp[0] = true;                              // 空集 = 凑出 0
for (int num : nums)                       // 外层：物品
    for (int j = target; j >= num; j--)    // 内层：容量·倒序（0-1！）
        dp[j] = dp[j] || dp[j - num];      // 不选 || 选
return dp[target];
```

### 变式 B 详解（322 零钱兑换）
```java
int[] dp = new int[amount + 1];
Arrays.fill(dp, amount + 1);               // ∞ 哨兵（用 amount+1 防溢出）
dp[0] = 0;
for (int coin : coins)                     // 外层：物品
    for (int j = coin; j <= amount; j++)   // 内层：容量·正序（完全！）
        dp[j] = Math.min(dp[j], dp[j - coin] + 1);
return dp[amount] == amount + 1 ? -1 : dp[amount];
```

### 变式 C / D 方案数（518 vs 377，内外层不同）
```java
// C 组合（顺序无关）：外层物品
for (int coin : coins)
    for (int j = coin; j <= amount; j++)
        dp[j] += dp[j - coin];

// D 排列（顺序有关）：外层容量
for (int j = 1; j <= amount; j++)
    for (int coin : coins)
        if (j >= coin) dp[j] += dp[j - coin];
```

### 记忆口诀

> **"能几次定倒正，求什么定转移，方案数里顺序定内外。"**
>
> 类比：**0-1 = 自助餐每个菜只能夹一次** → 倒序（防止一数多吃）；**完全 = 自助餐随便续** → 正序。

## 六、决策树：从题目到方法

```
看到一道题
│
├─ 是"最长/最少/最大/方案数/能不能"吗？
│    └─ 否 → 可能是双指针/贪心/模拟/二分/回溯
│    └─ 是 ↓
├─ 有一堆"东西" + 一个"目标值"吗？
│    ├─ 是 → ⭐ 背包题！
│    │      Q1 每个能用几次？一次=0-1(倒序)  无限=完全(正序)
│    │      Q2 求什么？能不能/最少/最多/方案数 → 定转移
│    │      Q3 方案数？顺序有关吗 → 定内外层
│    └─ 否 ↓
├─ 是"序列/子序列/子数组"问题？
│    ├─ 一维够吗？
│    │    ├─ 只看前1-2个 → 骨架 A（斐波那契）或 B（选不选）
│    │    ├─ 看任意前面 → 骨架 C（以i结尾）
│    │    └─ 一个量不够 → 骨架 D（双状态）
│    └─ 要二维？
│         ├─ 矩阵走路 → 骨架 E（路径）
│         ├─ 两个字符串 → 骨架 F（双串）
│         └─ 一个串的区间 → 骨架 G（区间）
```

## 七、易错点清单

1. **dp 含义没想清就写** → 必错（第 ① 步永远是含义，"以 i 结尾"还是"前 i 个"？）
2. **初始化漏 dp[0]** → 416 全盘皆输的教训（地基没打，整栋楼塌）
3. **0-1 和完全搞反** → 内层倒/正反了 = "一数多吃"（把 0-1 写成正序）或"漏选"
4. **数组 vs 滚动变量判断错** → 看转移依赖范围（前 1-2 个滚动，任意前面数组）
5. **方案数叠加漏初始化 dp[0]=1**
6. **∞ 哨兵用 Integer.MAX_VALUE** → +1 会溢出成负数！用 `amount+1` / `n+1`
7. **区间 DP 遍历顺序** → 按区间长度从小到大，不是普通 i 递增

## 八、复杂度速查

| 骨架 / 类型 | 时间复杂度 | 空间复杂度 |
|------------|-----------|-----------|
| 一维线性（A/B/D） | O(n) | O(1) 滚动 |
| 一维"以 i 结尾"（C） | O(n²) | O(n) |
| 二维矩阵（E） | O(m×n) | O(m×n) → O(n) |
| 二维双串（F） | O(m×n) | O(m×n) → O(n) |
| 区间（G） | O(n²) | O(n²) |
| 背包 | O(n × cap) | O(cap) |
