## 一、位运算

### 核心性质

| 运算 | 规则 | 用途 |
|------|------|------|
| a ^ 0 = a | 任何数与 0 异或不变 | 保留原值 |
| a ^ a = 0 | 任何数与自身异或为 0 | 消除成对出现的数 |
| a ^ b ^ a = b | 异或满足交换律和结合律 | 找唯一出现一次的数 |
| a & (-a) | 取最低位的 1 | 树状数组、位运算技巧 |
| a & (a - 1) | 去掉最低位的 1 | 数 1 个数 / 判断 2 的幂 |

### 七个位运算符

| 符号 | 名称 | 规则 | 例子 |
|------|------|------|------|
| `&` | 与 | 都 1 才 1 | `6 & 3 = 2`（110 & 011 = 010）|
| `\|` | 或 | 有 1 就 1 | `6 \| 3 = 7`（110 \| 011 = 111）|
| `^` | 异或 | 不同才 1 | `6 ^ 3 = 5`（110 ^ 011 = 101）|
| `~` | 取反 | 0↔1 全翻（连符号位） | `~5 = -6` |
| `<<` | 左移 | 左边补 0，×2ⁿ | `1 << 3 = 8` |
| `>>` | 右移 | 保留符号位，÷2ⁿ | `-8 >> 1 = -4` |
| `>>>` | 无符号右移 | 高位补 0 | `-8 >>> 1 = 2147483644` |

> ⚠️ **`>>` vs `>>>`**：`>>` 算术右移（负数补 1），`>>>` 逻辑右移（一律补 0）。刷题 99% 用 `>>`。

### ⭐ 十大常用套路

| # | 套路 | 写法 | 用途 |
|---|------|------|------|
| 1 | 判断奇偶 | `(n & 1) == 1` → 奇数 | 比 `n % 2` 快 |
| 2 | 去掉最低位的 1 | `n & (n - 1)` | ⭐ 数 1 个数 / 判断 2 的幂 |
| 3 | 取最低位的 1 | `n & (-n)` | lowbit，树状数组核心 |
| 4 | 判断 2 的幂 | `n > 0 && (n & (n-1)) == 0` | 231 题 |
| 5 | 取某一位 | `(n >> k) & 1` | 看第 k 位是 0 是 1 |
| 6 | 置某一位为 1 | `n \|= (1 << k)` | 状态压缩 |
| 7 | 清某一位为 0 | `n &= ~(1 << k)` | 状态压缩 |
| 8 | 交换两数 | `a^=b; b^=a; a^=b;` | 不用临时变量（炫技）|
| 9 | 异或自消 | `a ^ a = 0` | 136 唯一数 |
| 10 | 取绝对值 | `(n ^ (n>>31)) - (n>>31)` | 少见，了解即可 |

### 套路 2 详解：`n & (n - 1)`（最常用）

**作用：把 n 的二进制里最低位的那个 1 变成 0。**

```
n     = 12 = 1100
n - 1 = 11 = 1011
1100 & 1011 = 1000 = 8     ← 最低位的 1（第三位）被清掉了
```

**应用 A · 数二进制里 1 的个数（191 题）：**
```java
public int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= (n - 1);   // 每轮干掉一个 1
        count++;
    }
    return count;
}
```

**应用 B · 判断 2 的幂（231 题）：** 2 的幂二进制只有一个 1。
```java
public boolean isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;   // 只有一个1 → 干掉就变0
}
```

### ⭐ 只出现一次的数字

```java
public int singleNumber(int[] nums) {
    int res = 0;
    for (int num : nums) {
        res ^= num;
    }
    return res;
}
```

### 异或扩展题型（136 的亲戚）

| 题目 | 变体 | 核心思路 |
|------|------|---------|
| 136 只出现一次 | 其余出现 2 次 | 全部异或 → 唯一数 |
| 137 只出现一次 II | 其余出现 3 次 | 逐位统计 %3（异或不够用了）|
| 260 只出现一次 III | 有 2 个唯一数 | 全部异或得 `a^b`，按某一位分组再异或 |
| 268 丢失的数字 | 0~n 缺一个 | `缺失 = 全部异或(下标+值)` |
| 461 汉明距离 | 两数二进制差异 | `x^y` 后数 1 的个数 |

**268 丢失的数字（异或妙用）：**
```java
// nums = [0,1,3]，长度 3，缺 2
public int missingNumber(int[] nums) {
    int res = nums.length;              // 先异或上 n
    for (int i = 0; i < nums.length; i++) {
        res ^= i ^ nums[i];             // 下标 i 和值 nums[i] 都异或进去
    }
    return res;
}
// 下标(0,1,2) + 值(0,1,3) + n(3) 全部异或：
// 0^0 抵消、1^1 抵消、3^3 抵消 → 只剩 2 ✅
```

### 代码书写注意（Java 特有坑）

1. **运算符优先级坑**：位运算优先级比 `==` 低！必须加括号：
   ```java
   if ((n & 1) == 1) { }   // ✅ 加括号
   if (n & 1 == 1) { }     // ❌ 编译报错/逻辑错（== 先算）
   ```
2. **`int` 是 32 位有符号**，`1 << 31` 会溢出成负数，`1L << 40` 要用 long。
3. **`^` 不是幂**：Java 里 `a ^ b` 是异或，**没有幂运算符**（幂用 `Math.pow`）。别把异或当乘方。
4. **`~x` 取反连符号位一起翻**，所以 `~5 = -6`（不是 2），负数先跳过。

## 二、摩尔投票法

### 核心思想

不同元素互相抵消，最后剩下的就是众数（出现次数 > n/2 的候选）。

```java
public int majorityElement(int[] nums) {
    int candidate = nums[0];
    int count = 1;
    
    for (int i = 1; i < nums.length; i++) {
        if (count == 0) {
            candidate = nums[i];
            count = 1;
        } else if (nums[i] == candidate) {
            count++;
        } else {
            count--;
        }
    }
    
    return candidate;
}
```

## 三、荷兰国旗问题（三指针）

### 核心思想

用三个指针（p0, p1, p2）将数组分为三个区域：0 区、1 区（处理区）、2 区。

```java
public void sortColors(int[] nums) {
    int p0 = 0;                // 0 的右边界
    int cur = 0;               // 当前处理位置
    int p2 = nums.length - 1;  // 2 的左边界
    
    while (cur <= p2) {
        if (nums[cur] == 0) {
            int temp = nums[p0];
            nums[p0] = nums[cur];
            nums[cur] = temp;
            p0++;
            cur++;
        } else if (nums[cur] == 2) {
            int temp = nums[p2];
            nums[p2] = nums[cur];
            nums[cur] = temp;
            p2--;
            // cur 不 +1，因为交换过来的值还没处理
        } else {  // nums[cur] == 1
            cur++;
        }
    }
}
```

## 四、下一个排列

### 核心步骤

```
1. 从右往左找第一个「升序对」(i, i+1)，即 nums[i] < nums[i+1]
2. 从右往左找第一个比 nums[i] 大的元素 nums[j]
3. 交换 nums[i] 和 nums[j]
4. 翻转 i+1 到末尾（使其变为升序/最小排列）
```

```java
public void nextPermutation(int[] nums) {
    // 1. 找第一个升序对
    int i = nums.length - 2;
    while (i >= 0 && nums[i] >= nums[i + 1]) {
        i--;
    }
    
    if (i >= 0) {
        // 2. 找第一个比 nums[i] 大的
        int j = nums.length - 1;
        while (j >= 0 && nums[j] <= nums[i]) {
            j--;
        }
        // 3. 交换
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
    
    // 4. 翻转 i+1 到末尾
    int left = i + 1, right = nums.length - 1;
    while (left < right) {
        int temp = nums[left];
        nums[left] = nums[right];
        nums[right] = temp;
        left++;
        right--;
    }
}
```

## 五、Floyd 判圈法（双指针找重复数）

把数组看成链表：`nums[i]` 的值表示下一个节点的索引。  
有重复数 = 有环，找环入口 = 找重复数。

```java
public int findDuplicate(int[] nums) {
    int slow = nums[0], fast = nums[0];
    
    // 第一阶段：快慢指针相遇
    do {
        slow = nums[slow];
        fast = nums[nums[fast]];
    } while (slow != fast);
    
    // 第二阶段：找环入口
    slow = nums[0];
    while (slow != fast) {
        slow = nums[slow];
        fast = nums[fast];
    }
    
    return slow;
}
```
