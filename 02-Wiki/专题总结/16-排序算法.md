## 一、快速排序 Quick Sort

> **一句话：** 选 pivot 分区（左小右大）→ pivot 落位 → 递归排两侧。**交换排序，不稳定。**

### 核心思想（分治三连）

```
partition：选 pivot，把数组分成 [小, pivot, 大]
    ↓  pivot 已经停在最终位置
递归左半 + 右半（pivot 不用再动）
```

- 时间复杂度：平均 O(n log n)，**最坏 O(n²)**（已排序数组 + 固定取头）→ **随机 pivot 可避免**
- 空间：O(log n)（递归栈）· **原地排序**（不需要额外数组，靠 swap）

### 挖坑填数法 partition（背这个）

```java
int partition(int[] nums, int left, int right) {
    // ⭐ 随机选 pivot，防已排序数组退化成 O(n²)
    Random rand = new Random();
    int pi = left + rand.nextInt(right - left + 1); // [left, right] 随机下标
    swap(nums, left, pi);                          // 换到最左边，统一处理

    int pivot = nums[left];        // 取 pivot，left 位置挖坑
    while (left < right) {
        while (left < right && nums[right] >= pivot) right--; // ① 先扫右：找小的填左坑
        nums[left] = nums[right];
        while (left < right && nums[left]  <= pivot) left++;  // ② 再扫左：找大的填右坑
        nums[right] = nums[left];
    }
    nums[left] = pivot;            // 坑位重合，pivot 归位
    return left;                   // pivot 最终位置
}
```

> 🧠 **口诀：** **"取左先扫右，取右先扫左。"** 坑挖在哪边，先从那边的对面找人填坑。
> ⚠️ **本次真实翻车：** 坑挖在 left 却先扫左 → 大元素被覆盖，**数据丢失**。

### 完整主逻辑

```java
void quickSort(int[] nums, int left, int right) {
    if (left >= right) return;                     // 空/单元素，天然有序
    int pos = partition(nums, left, right);        // pivot 落位
    quickSort(nums, left, pos - 1);                // 排左边
    quickSort(nums, pos + 1, right);               // 排右边
}
```

### 与 215 快选的关系

| | 快排 | 快选（215）|
|---|------|-----------|
| 递归 | 两侧都排 | 只排 k 所在那一侧 |
| 返回 | 整个有序数组 | 第 k 大 |
| 复杂度 | O(n log n) | 平均 O(n) |

**同一个 partition，只是"排一边还是排两边"的区别。**

## 二、归并排序 Merge Sort

> **一句话：** 对半切到单元素 → 两两合并成有序 → 一路合并回整数组。**分治，稳定。**

### 核心思想（分治三连）

```
分：对半切，递归排左、右（切到只剩 1 个）
合：两个有序区间，双指针取小合并（需要 temp 数组）
```

- 时间复杂度：**稳定 O(n log n)**（最坏也是）
- 空间：**O(n)**（temp 数组，这是它比快排"贵"的地方）
- **稳定**：合并时 `nums[i] <= nums[j]` 取左 → 相等元素左边先走，相对顺序不变

### 为什么需要 temp 数组？

合并两个有序区间时，直接在原数组上写会**覆盖还没比较的元素**。
→ 先写进 temp，再拷回 nums。**归并不能原地，快排可以。**

### 核心代码（背这个）

```java
void mergeSort(int[] nums, int left, int right, int[] temp) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;     // ⭐ 防溢出写法（left+right 可能越界）
    mergeSort(nums, left, mid, temp);        // 分：排左
    mergeSort(nums, mid + 1, right, temp);   // 分：排右
    merge(nums, left, mid, right, temp);     // 合
}

void merge(int[] nums, int left, int mid, int right, int[] temp) {
    int i = left, j = mid + 1, k = left;     // i 指左半、j 指右半、k 写 temp
    while (i <= mid && j <= right) {         // ① 两边都有：谁小谁进
        if (nums[i] <= nums[j]) temp[k++] = nums[i++];
        else                    temp[k++] = nums[j++];
    }
    while (i <= mid) temp[k++] = nums[i++];  // ② 左剩：直接搬
    while (j <= right) temp[k++] = nums[j++];// ③ 右剩：直接搬
    for (int p = left; p <= right; p++)      // ④ 拷回 nums
        nums[p] = temp[p];
}
```

> 🧠 **类比：** 合并两副已排序扑克牌——每步比两边的牌，小的拿走；一边空了另一边直接顺下去。

## 三、快排 vs 归并 一表看懂

| | 快排 | 归并 |
|---|------|------|
| 思想 | 先分区、后递归（先难后易）| 先递归、后合并（先易后难）|
| 额外空间 | O(log n) 递归栈 | **O(n) temp 数组** |
| 稳定性 | ❌ 不稳定 | ✅ 稳定 |
| 最坏时间 | O(n²)（随机 pivot 可避免）| 稳定 O(n log n) |
| 原地 | ✅ | ❌ |
| 典型应用 | 215 快选、TopK | 链表排序 148、逆序对 |

**一句话选择：** 手撕数组排序默认快排（省空间）；要稳定或链表场景用归并。
