## 一、三种手撕算法模式（必读 ⭐）

**按重要程度：`一片空白模式` >> `核心代码模式` >> `ACM模式`**

| 模式 | 是什么 | 在哪遇到 | 重点注意 |
|------|--------|----------|----------|
| 🅰️ 一片空白 | 打开一个空 txt，main / 测试用例 / 类定义 / 导入全自己写 | 面试手撕 **70%** | 自定义类 + 构造函数 + 写死测试数据 + import |
| 🅱️ 核心代码 | LeetCode 风格，只写 Solution 的函数 | 面试手撕 30% + 日常刷题 | 核心函数逻辑本身 |
| 🅲 ACM | Scanner 读入 + System.out 输出 | 笔试 | 正确读入格式（不需要平时用 ACM 刷题）|

> 💡 **日常怎么练：** 平时用**核心代码模式**刷题即可（函数逻辑最重要）。**每周末挑 2-3 题**用**一片空白模式**从零写一遍（含测试用例）。**笔试前**突击 ACM 模式的 Scanner 读入。

### 🧩 自定义类（一片空白模式必须会）

```java
// 单向链表
class ListNode {
    int val;
    ListNode next;

    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

// 双向链表
class DoubleListNode {
    int val;
    DoubleListNode prev;
    DoubleListNode next;

    DoubleListNode() {}
    DoubleListNode(int val) { this.val = val; }
    DoubleListNode(int val, DoubleListNode prev, DoubleListNode next) {
        this.val = val; this.prev = prev; this.next = next;
    }
}

// 二叉树节点
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val; this.left = left; this.right = right;
    }
}
```

> ⚠️ **构造函数必须掌握！** 很多同学面试写数据结构时卡在"不会写构造函数"——背熟上面 6 个。

## 四、每题核心思路 + 易错点（复习用 ⭐）

> 按上面 5 天分组，做题前扫一眼"核心思路"，做完对一遍"易错点"。

### Day 1 · 链表重头戏

| 题 | 核心思路 | 易错点 |
|----|----------|--------|
| **206 反转链表** | 三指针 pre/cur/tmp 原地掉头；递归"接尾巴" `head.next.next=head` | 改 next 前先存 tmp；递归基准 `head==null || head.next==null` |
| **92 反转链表 II** | 虚拟头 + 定位 left 前驱 pre + 组内反转（同 206）+ 三步重连 | left 可能是 1 → 必须 dummy；重连顺序：pre.next→反转尾，反转头→pre.next.next |
| **25 K 个一组翻转** | `while(true)` 中间出口 + 探测够 K 个 + 组内反转 + 三步重连 | 探测用 for 走 K 步判 null；每组前保存 next 组起点 |
| **21 合并两链表** | 虚拟头 + 双指针取小 | 改"别人的" next 不用 temp；循环后接剩余 |
| **23 合并 K 个** | 小顶堆 offer 各链头，poll 最小接尾 + offer 它的 next；或分治两两合并 | 堆比较器 `(a,b)->a.val-b.val`；防 null |
| **146 LRU** | HashMap(找 O(1)) + 双向链表(顺序)；get 也 moveToHead；满删尾 + 同步删 map | remove 2 行 / pushFront 4 行；哨兵免判空；get 记得返回 val |
| **160 相交链表** | 双指针交错：pA 走完换 B、pB 走完换 A，总路程相等 | 判**同一节点**用引用 `==`，判值才 `.val==` |
| **141 环形链表** | 快慢指针：fast 走 2、slow 走 1，相遇=有环 | `while(fast!=null && fast.next!=null)` |

### Day 2 · 链表续 + 哈希/双指针

| 题 | 核心思路 | 易错点 |
|----|----------|--------|
| **142 环形链表 II** | 相遇后 fast 回 head，两指针同步走一步，再相遇=入口 | 第二阶段 fast 也是一次走一步（不是两步）|
| **143 重排链表** | 找中点切断（fast=head.next 慢半步）+ 反转后半 + 交错合并 | 中点慢半步；合并时先存 next 再连 |
| **19 删倒数第 N 个** | 虚拟头 + fast 先走 n 步 + 同步走到尾 + 跳过目标 | dummy 防删头；fast 先走 n 步循环条件 |
| **82 删重复元素 II** | 虚拟头 + 判断 `cur.next.val == cur.next.next.val`，相等则跳过整段（while 收集）| ⭐ 是删**全部**重复不是留一个；判空 `cur.next!=null && cur.next.next!=null` |
| **1 两数之和** | 哈希表边遍历边查，先查再存 | 返回下标；同一个元素不能用两次（先查后存）|
| **3 无重复最长子串** | 滑动窗口：右扩 + 遇重复把 left 跳到上次位置+1 | 更新 max 时机；left 跳跃是 `max(left, map.get(c)+1)` |
| **15 三数之和** | 排序 + 固定 i + 双指针 l/r + 去重 | 去重三处：i、l、r；`sum>0` 右移 r |
| **88 合并两有序数组** | 从后往前归并（nums1 尾部空闲），三指针 i/j/k | 剩余部分复制；`i>=0 && j>=0` 双条件 |

### Day 3 · 树 + 回溯 + 图

| 题 | 核心思路 | 易错点 |
|----|----------|--------|
| **102 层序遍历** | BFS：固定 size 弹本层 + offer 孩子 + add 层 | ⭐ size 必须**固定**在循环前取，不能动态 `queue.size()` |
| **103 锯齿层序** | BFS + 标志位：奇数层反转 / 偶数层正常 | `LinkedList.addFirst` vs `addLast`，或 `Collections.reverse` |
| **199 右视图** | BFS 每层取最后一个；或 DFS 先右后左记首次深度 | 层序时 `i==size-1` 才 add |
| **236 最近公共祖先** | 后序递归：左右都非空 → 当前节点；单边非空 → 返回那边 | 基准：p/q 之一就是当前根，直接返回 |
| **124 最大路径和** | 后序 + 全局 max：单臂上返 `max(0, ...)+val`，双臂更新全局 | ⭐ 负贡献取 0（`Math.max(0, x)`）；max 初始 `MIN_VALUE` 不是 0 |
| **46 全排列** | res/path/used 三件套；叶子收集快照 | `res.add(new ArrayList<>(path))` 拷贝，不是存引用 |
| **93 复原 IP** | 回溯 4 段，每段 1-3 位；剪枝：前导 0 且非单 0、>255 | 剩余长度要够（`len-start >= 剩余段数`）；每段 `substring(start, i+1)` |
| **200 岛屿数量** | DFS 沉岛：遇 1 计数并四方向淹没 | 边界 `>=` 不是 `>`；访问前判 inBound |

### Day 4 · DP + 字符串

| 题 | 核心思路 | 易错点 |
|----|----------|--------|
| **5 最长回文子串** | 中心扩展：从 2n-1 个中心向两边扩；统一写法 `l=i/2, r=(i+1)/2` | ⭐ 长度 = `r-l-1`（l、r 各多走一步）；REV-77 两次未过重点默写 |
| **53 最大子数组和** | Kadane：`sum=max(num, sum+num)`，`max=Math.max(max,sum)` | sum 为负就重开；别忘更新全局 max |
| **121 买卖股票** | minPrice 历史最低 + maxProfit 差值最大 | 先更新 minPrice 再算 profit |
| **300 最长递增子序列** | `dp[i]=max(dp[i], dp[j]+1)` 枚举所有 j；或贪心+二分 tails | ⭐ 接棒人是**任意** `nums[j]<nums[i]`，不是只看 i-1（反例 [2,5,3,7]）|
| **72 编辑距离** | 双串 DP：相等 `dp[i-1][j-1]` / 不等 `min(删,插,替)+1` | `Math.min` 只收 2 参要嵌套；base `dp[i][0]=i` |
| **1143 最长公共子序列** | 双串 DP：相等 `+1` / 不等 `max(淘汰一边)` | 下标差 1 前缀法 `[m+1][n+1]`，空串天然 0 |
| **415 字符串相加** | 双指针从后往前 + 进位 carry；StringBuilder 逆序 | ⭐ carry 兜底最高位；`c-'0'` 转数字 |
| **165 比较版本号** | 按 '.' split + 逐段解析（忽略前导 0），不足补 0 | split 要转义 `"\\."`；每段 `Integer.parseInt` 或手算 |

### Day 5 · 排序 + 二分 + 综合

| 题 | 核心思路 | 易错点 |
|----|----------|--------|
| **912 排序数组** | 快排：分区 + 递归两侧；归并：分治 + 合并 | ⭐ 快排基准 `l>=r`；归并 temp 数组；两种都要能白板默写 |
| **215 第 K 大** | 快选（快排只排一边，平均 O(n)）或小根堆守 k 个 | 快选新 k 计算；堆版堆顶=第 k 大 |
| **33 搜索旋转数组** | 二分：`nums[left]<=nums[mid]` 判断左半有序；target 在有序半则去那半 | 边界用 `<=`；target 范围判断别漏等号 |
| **4 中位数** | 切割线二分（短数组二分 + `j=(m+n+1)/2-i`）或 findKth 递归淘汰 | ⭐ 哨兵 ±INF；奇偶分支；REV-58 挂起题优先回炉 |
| **56 合并区间** | 按起点排序 + 扫描合并：`pre.end>=cur.start` 则取 max end | Lambda 排序 `(a,b)->a[0]-b[0]`；合并更新 end 取 max |
| **42 接雨水** | 对撞双指针：维护 leftMax/rightMax，移动矮边 | ⭐ 每次移动的是**矮的一边**；`leftMax - height[left]` 累加 |
| **54 螺旋矩阵** | 边界收缩四方向：上→右→下→左 | 下/左方向要判断 `top<=bottom` 防重复 |
| **20 有效的括号** | 栈：左括号入栈，右括号弹栈比对 | 空栈 peek 崩（先判空）；最后栈非空=不合法 |

## 五、ACM 模式 · 输入输出速查（笔试前突击）

> ACM 模式**只需要注意如何用 Scanner 读对输入**，不需要平时就用它刷题。

| 输入类型 | 读法 |
|----------|------|
| 单个整数 | `int n = sc.nextInt();` |
| 数组 | `int[] arr = new int[n]; for(...) arr[i]=sc.nextInt();` |
| 二维矩阵 | `int m=sc.nextInt(), n=sc.nextInt(); int[][] grid=new int[m][n];` 双层 for |
| 字符串（无空格）| `String s = sc.next();` |
| 字符串（含空格）| `sc.nextLine();`（先吃掉上一行残留换行再读）|
| 输出 | `System.out.println(结果);` |
| 多组输入 | `while (sc.hasNext()) { ... }` |
