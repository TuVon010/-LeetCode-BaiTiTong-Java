## 一、一图看懂二维数组

```java
int[][] matrix = new int[3][4];   // 3 行 4 列
//             行数↑ 列数↑

matrix =
[
  [ 1,  2,  3,  4 ],   ← 第 0 行 (row 0)
  [ 5,  6,  7,  8 ],   ← 第 1 行 (row 1)
  [ 9, 10, 11, 12 ]    ← 第 2 行 (row 2)
]
   ↑   ↑   ↑   ↑
 第0列 第1列 第2列 第3列
```

## 二、三个必须背下的公式 ⭐

| 你想表达 | 写法 | 记住 |
|---------|------|------|
| **行数** | `matrix.length` | 数组有几个"大格子" |
| **列数** | `matrix[0].length` | 第 0 行有几个"小格子" |
| **第 i 行第 j 列** | `matrix[i][j]` | i 管行，j 管列 |

> 🧠 **记忆口诀：**
> - `matrix.length` = **行数**（外层长度）
> - `matrix[0].length` = **列数**（内层长度）
> - `matrix[i][j]` = 先选行 i，再选列 j

## 三、遍历二维数组的两种姿势

### 姿势 1：双 for 循环（最常用）

```java
int m = matrix.length;      // 行数
int n = matrix[0].length;   // 列数

for (int i = 0; i < m; i++) {        // i 遍历行
    for (int j = 0; j < n; j++) {    // j 遍历列
        System.out.println(matrix[i][j]);
    }
}
```

### 姿势 2：for-each

```java
for (int[] row : matrix) {       // 每行是一个 int[]
    for (int val : row) {        // 行里的每个元素
        System.out.println(val);
    }
}
```

## 四、按"行/列"处理时的判断

这是矩阵题最容易晕的地方。**想清楚你要处理的是行还是列：**

| 你想做的事 | 遍历谁 | 代码 |
|-----------|--------|------|
| **第 i 行整行置零** | 遍历**列**（n 次）| `for (j...) matrix[i][j] = 0;` |
| **第 j 列整列置零** | 遍历**行**（m 次）| `for (i...) matrix[i][j] = 0;` |
| **遍历所有格子** | 先行后列 | `for (i) for (j)` |

> 🧠 **关键：处理"行"→ 动 j（列）；处理"列"→ 动 i（行）。** 因为 `matrix[i][j]` 里，i 是行下标、j 是列下标。想让一整行变，就固定 i、让 j 变化；想让一整列变，就固定 j、让 i 变化。

## 五、自测题

```java
int[][] matrix = new int[3][5];   // 3行5列

// 1. 行数是多少？ → matrix.______
// 2. 列数是多少？ → matrix[0].______
// 3. 第2行第4列的元素 → matrix[__][__]
// 4. 把第0行整行置零 → for (int j...) matrix[__][__] = 0;
// 5. 把第1列整列置零 → for (int i...) matrix[__][__] = 0;
```

<details>
<summary>点击看答案</summary>

1. `matrix.length` = 3
2. `matrix[0].length` = 5
3. `matrix[2][4]`
4. `for (int j...) matrix[0][j] = 0;`（固定 i=0，动 j）
5. `for (int i...) matrix[i][1] = 0;`（固定 j=1，动 i）

</details>
