## 1. 哈希表

### 核心知识点

哈希表是算法面试中最基础也最常用的数据结构。它的核心价值是**将查找时间从 O(n) 降低到 O(1)**。

**四大应用场景：**

| 场景 | 说明 | 典型题目 |
|------|------|----------|
| 查找 | 快速判断元素是否存在 | 两数之和 |
| 去重 | 判断元素是否重复出现 | 存在重复元素 |
| 计数 | 统计元素出现次数 | 字母异位词分组 |
| 分组 | 按某种规则将元素分组 | 最长连续序列 |

**Java 中的哈希表工具：**

```java
// 1. HashMap（普通字典）
Map<String, String> map = new HashMap<>();
map.put("key", "value");
if (map.containsKey("key")) {  // O(1) 查找
    String val = map.get("key");
}

// 2. 计数（类似Python的Counter）
Map<Integer, Integer> count = new HashMap<>();
for (int num : nums) {
    count.put(num, count.getOrDefault(num, 0) + 1);
}

// 3. 分组（类似Python的defaultdict(list)）
Map<String, List<String>> groups = new HashMap<>();
for (String s : strs) {
    groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
}

// 4. 带默认值的计数（类似Python的defaultdict(int)）
Map<String, Integer> dd = new HashMap<>();
dd.put("key", dd.getOrDefault("key", 0) + 1);  // 无需初始化
```

### 模板代码

```java
// 模板1：两数之和类（查找互补元素）
public int[] hashLookup(int[] nums, int target) {
    Map<Integer, Integer> seen = new HashMap<>();  // 值 -> 索引
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (seen.containsKey(complement)) {
            return new int[]{seen.get(complement), i};
        }
        seen.put(nums[i], i);
    }
    return new int[]{};
}

// 模板2：计数+分组
public List<List<String>> hashGroup(String[] strs) {
    Map<String, List<String>> groups = new HashMap<>();
    for (String s : strs) {
        char[] chars = s.toCharArray();
        Arrays.sort(chars);
        String key = new String(chars);  // 用排序结果作为分组key
        groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(groups.values());
}
```

## 2. 双指针

### 核心知识点

双指针的核心思想是**利用两个指针的相对运动来减少搜索空间**，将 O(n^2) 降低到 O(n)。

**两种经典模式：**

1. **对撞指针（左右指针）**：两个指针从两端向中间移动，适用于有序数组
2. **快慢指针**：两个指针同向移动但速度不同，适用于链表和数组中的位置关系

### 模板代码

```java
// 模板1：对撞指针（有序数组）
public int[] twoPointersCollision(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int s = nums[left] + nums[right];
        if (s == target) {
            return new int[]{left, right};
        } else if (s < target) {
            left++;     // 和太小，左指针右移增大
        } else {
            right--;    // 和太大，右指针左移减小
        }
    }
    return new int[]{};
}

// 模板2：快慢指针（链表中找环/中点）
public ListNode fastSlowPointer(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;           // 慢指针走一步
        fast = fast.next.next;      // 快指针走两步
    }
    // 如果有环，fast会追上slow
    // 如果无环，fast到达末尾时slow在中点
    return slow;
}

// 模板3：同向双指针（原地修改数组）
public int removeDuplicates(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    return slow + 1;
}
```

## 3. 滑动窗口

### 核心知识点

滑动窗口本质上是**双指针的变体**，用于解决连续子数组/子串问题。

**labuladong 三问判断法：**
1. 什么时候扩大窗口？（右指针移动的条件）
2. 什么时候缩小窗口？（左指针移动的条件）
3. 答案在什么时候更新？（扩大时还是缩小时）

### 模板代码

```java
// 模板1：定长滑动窗口（窗口大小固定为k）
public int fixedWindow(int[] nums, int k) {
    int windowSum = 0;
    for (int i = 0; i < k; i++) {  // 第一个窗口
        windowSum += nums[i];
    }
    int maxSum = windowSum;
    for (int i = k; i < nums.length; i++) {
        windowSum += nums[i] - nums[i - k];  // 滑入新元素，滑出旧元素
        maxSum = Math.max(maxSum, windowSum);
    }
    return maxSum;
}

// 模板2：不定长滑动窗口（通用模板）
public int slidingWindow(String s) {
    Map<Character, Integer> window = new HashMap<>();  // 窗口内的数据
    Map<Character, Integer> need = new HashMap<>();    // 需要满足的条件

    int left = 0;
    int result = 0;  // 或 Integer.MAX_VALUE，取决于求最大还是最小

    for (int right = 0; right < s.length(); right++) {
        // 1. 扩大窗口：右指针元素进入窗口
        char c = s.charAt(right);
        window.put(c, window.getOrDefault(c, 0) + 1);

        // 2. 判断是否需要缩小窗口
        while (/* 窗口需要缩小的条件 */) {
            // 3. 缩小窗口：左指针元素离开窗口
            char d = s.charAt(left);
            window.put(d, window.get(d) - 1);
            left++;
        }

        // 4. 更新答案（根据题意决定在扩大还是缩小时更新）
        result = Math.max(result, right - left + 1);
    }

    return result;
}

// 模板3：求最长满足条件的子串（具体示例）
public int lengthOfLongestSubstring(String s) {
    Set<Character> charSet = new HashSet<>();
    int left = 0;
    int maxLen = 0;
    for (int right = 0; right < s.length(); right++) {
        while (charSet.contains(s.charAt(right))) {     // 窗口内有重复字符，需要缩小
            charSet.remove(s.charAt(left));
            left++;
        }
        charSet.add(s.charAt(right));                   // 加入新字符
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

## 4. 前缀和

### 核心知识点

前缀和的核心思想是**预处理一个前缀和数组，使得任意区间的和可以在 O(1) 时间内求出**。

- `prefix[i] = nums[0] + nums[1] + ... + nums[i-1]`
- 区间和 `sum(nums[i..j]) = prefix[j+1] - prefix[i]`

**进阶用法**：前缀和 + 哈希表，用于解决"和为K的子数组"类问题。

### 模板代码

```java
// 模板1：前缀和数组
public int[] prefixSum(int[] nums) {
    int n = nums.length;
    int[] prefix = new int[n + 1];   // prefix[0] = 0, prefix[i] = sum(nums[0..i-1])
    for (int i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + nums[i];
    }
    // 查询区间 [i, j] 的和: prefix[j + 1] - prefix[i]
    return prefix;
}

// 模板2：前缀和 + 哈希表（求和为k的子数组个数）
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1);     // 前缀和为0出现1次（空前缀）
    int currentSum = 0;
    int count = 0;
    for (int num : nums) {
        currentSum += num;
        // 如果存在之前的前缀和 = currentSum - k
        // 说明从那个位置到当前位置的子数组和为k
        count += prefixCount.getOrDefault(currentSum - k, 0);
        prefixCount.put(currentSum, prefixCount.getOrDefault(currentSum, 0) + 1);
    }
    return count;
}
```

## 5. 单调队列 / 单调栈

### 核心知识点

- **单调队列**：队列内元素单调递增或递减，用于解决**滑动窗口中的最值问题**
- **单调栈**：栈内元素单调递增或递减，用于解决**下一个更大/更小元素问题**

### 模板代码

```java
// 模板1：单调队列（滑动窗口最大值）
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] result = new int[n - k + 1];
    Deque<Integer> dq = new ArrayDeque<>();  // 存储索引，队列中的索引对应的值单调递减
    int idx = 0;

    for (int i = 0; i < n; i++) {
        // 1. 移除窗口外的元素
        while (!dq.isEmpty() && dq.peekFirst() < i - k + 1) {
            dq.pollFirst();
        }
        // 2. 维护单调性：移除比当前元素小的队尾元素
        while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) {
            dq.pollLast();
        }
        // 3. 加入当前元素
        dq.addLast(i);
        // 4. 记录结果（窗口形成后）
        if (i >= k - 1) {
            result[idx++] = nums[dq.peekFirst()];  // 队首就是最大值
        }
    }
    return result;
}

// 模板2：单调栈（下一个更大元素）
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>();  // 存储索引，栈底到栈顶单调递减

    for (int i = 0; i < n; i++) {
        // 当前元素比栈顶大，说明找到了栈顶元素的"下一个更大元素"
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
            int idx = stack.pop();
            result[idx] = nums[i];
        }
        stack.push(i);
    }
    return result;
}

// 模板3：单调栈（环形数组版本，遍历两遍）
public int[] nextGreaterElementCircular(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < 2 * n; i++) {
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i % n]) {
            int idx = stack.pop();
            result[idx] = nums[i % n];
        }
        stack.push(i % n);
    }
    return result;
}
```

## 6. 链表操作

### 核心知识点

**三大核心技巧：**
1. **虚拟头节点（dummy node）**：避免对头节点的特殊处理
2. **快慢指针**：找中点、找环、找第k个节点
3. **链表反转**：迭代法和递归法

### 模板代码

```java
// 链表节点定义
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

// 模板1：虚拟头节点
public ListNode useDummyNode(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode curr = dummy;
    while (curr.next != null) {
        // 操作 curr.next
        curr = curr.next;
    }
    return dummy.next;
}

// 模板2：链表反转（迭代法）
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode nxt = curr.next;    // 保存下一个节点
        curr.next = prev;            // 反转指针
        prev = curr;                 // 前进prev
        curr = nxt;                  // 前进curr
    }
    return prev;  // prev是新的头节点
}

// 模板3：链表反转（递归法）
public ListNode reverseListRecursive(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }
    ListNode newHead = reverseListRecursive(head.next);
    head.next.next = head;   // 让下一个节点指向自己
    head.next = null;        // 断开原来的指向
    return newHead;
}

// 模板4：快慢指针找链表中点
public ListNode findMiddle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;  // slow就是中点（偶数长度时为中间偏右）
}

// 模板5：判断链表是否有环
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            return true;
        }
    }
    return false;
}

// 模板6：找环的入口
public ListNode detectCycleEntry(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            // 一个指针从头开始，另一个从相遇点开始
            // 两者每次走一步，再次相遇就是入口
            slow = head;
            while (slow != fast) {
                slow = slow.next;
                fast = fast.next;
            }
            return slow;
        }
    }
    return null;
}

// 模板7：合并两个有序链表
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode curr = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            curr.next = l1;
            l1 = l1.next;
        } else {
            curr.next = l2;
            l2 = l2.next;
        }
        curr = curr.next;
    }
    curr.next = (l1 != null) ? l1 : l2;  // 接上剩余部分
    return dummy.next;
}
```

## 7. 二叉树

### 核心知识点

二叉树的题目几乎都可以用**递归**解决。递归的关键是明确：**函数的定义是什么（做什么）、base case是什么、递归关系是什么。**

**二叉树分治法**：通过左右子树的信息来推导当前树的信息（如最大深度、直径、LCA等）。

**BST（二叉搜索树）特性**：左 < 根 < 右，中序遍历是有序的。

### 模板代码

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

// ========== 递归遍历 ==========

// 前序遍历：根 -> 左 -> 右
public List<Integer> preorder(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    result.add(root.val);
    result.addAll(preorder(root.left));
    result.addAll(preorder(root.right));
    return result;
}

// 中序遍历：左 -> 根 -> 右
public List<Integer> inorder(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    result.addAll(inorder(root.left));
    result.add(root.val);
    result.addAll(inorder(root.right));
    return result;
}

// 后序遍历：左 -> 右 -> 根
public List<Integer> postorder(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    result.addAll(postorder(root.left));
    result.addAll(postorder(root.right));
    result.add(root.val);
    return result;
}

// ========== 迭代遍历 ==========

// 前序遍历（迭代）
public List<Integer> preorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.add(node.val);
        if (node.right != null) stack.push(node.right);   // 先压右，后处理
        if (node.left != null) stack.push(node.left);     // 后压左，先处理
    }
    return result;
}

// 中序遍历（迭代）
public List<Integer> inorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode curr = root;
    while (curr != null || !stack.isEmpty()) {
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;         // 一路向左
        }
        curr = stack.pop();
        result.add(curr.val);         // 处理节点
        curr = curr.right;            // 转向右子树
    }
    return result;
}

// ========== BFS层序遍历 ==========

public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        int levelSize = queue.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.pollFirst();
            level.add(node.val);
            if (node.left != null) queue.add(node.left);
            if (node.right != null) queue.add(node.right);
        }
        result.add(level);
    }
    return result;
}

// ========== 二叉树分治法 ==========

// 最大深度
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    int leftDepth = maxDepth(root.left);
    int rightDepth = maxDepth(root.right);
    return 1 + Math.max(leftDepth, rightDepth);
}

// 翻转二叉树
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode temp = root.left;
    root.left = invertTree(root.right);
    root.right = invertTree(temp);
    return root;
}

// 判断对称二叉树
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    return check(root.left, root.right);
}

private boolean check(TreeNode left, TreeNode right) {
    if (left == null && right == null) return true;
    if (left == null || right == null) return false;
    return (left.val == right.val &&
            check(left.left, right.right) &&
            check(left.right, right.left));
}

// 最近公共祖先（LCA）
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;   // p和q分别在两侧
    return left != null ? left : right;                // p和q在同一侧
}

// ========== BST操作 ==========

// BST搜索
public TreeNode searchBST(TreeNode root, int val) {
    if (root == null || root.val == val) return root;
    if (val < root.val) return searchBST(root.left, val);
    return searchBST(root.right, val);
}

// BST验证（中序遍历是否有序）
public boolean isValidBST(TreeNode root) {
    return validate(root, null, null);
}

private boolean validate(TreeNode node, Integer low, Integer high) {
    if (node == null) return true;
    if ((low != null && node.val <= low) || (high != null && node.val >= high)) {
        return false;
    }
    return validate(node.left, low, node.val) && validate(node.right, node.val, high);
}
```

## 8. 图论

### 核心知识点

图论问题主要包含：
- **DFS/BFS遍历**：搜索所有路径、最短路径
- **并查集**：判断连通性、合并集合
- **拓扑排序**：有向无环图（DAG）的排序
- **字典树（Trie）**：前缀匹配、词频统计

### 模板代码

```java
// ========== DFS模板 ==========

public List<Integer> dfs(Map<Integer, List<Integer>> graph, int start) {
    Set<Integer> visited = new HashSet<>();
    List<Integer> result = new ArrayList<>();
    dfsHelper(graph, start, visited, result);
    return result;
}

private void dfsHelper(Map<Integer, List<Integer>> graph, int node,
                       Set<Integer> visited, List<Integer> result) {
    if (visited.contains(node)) return;
    visited.add(node);
    result.add(node);
    for (int neighbor : graph.getOrDefault(node, new ArrayList<>())) {
        dfsHelper(graph, neighbor, visited, result);
    }
}

// ========== BFS模板 ==========

public List<Integer> bfs(Map<Integer, List<Integer>> graph, int start) {
    Set<Integer> visited = new HashSet<>();
    Deque<Integer> queue = new ArrayDeque<>();
    List<Integer> result = new ArrayList<>();
    visited.add(start);
    queue.add(start);
    while (!queue.isEmpty()) {
        int node = queue.pollFirst();
        result.add(node);
        for (int neighbor : graph.getOrDefault(node, new ArrayList<>())) {
            if (!visited.contains(neighbor)) {
                visited.add(neighbor);
                queue.add(neighbor);
            }
        }
    }
    return result;
}

// BFS求最短路径（无权图）
public int bfsShortestPath(Map<Integer, List<Integer>> graph, int start, int end) {
    Set<Integer> visited = new HashSet<>();
    Deque<int[]> queue = new ArrayDeque<>();  // (当前节点, 距离)
    visited.add(start);
    queue.add(new int[]{start, 0});
    while (!queue.isEmpty()) {
        int[] curr = queue.pollFirst();
        int node = curr[0], dist = curr[1];
        if (node == end) return dist;
        for (int neighbor : graph.getOrDefault(node, new ArrayList<>())) {
            if (!visited.contains(neighbor)) {
                visited.add(neighbor);
                queue.add(new int[]{neighbor, dist + 1});
            }
        }
    }
    return -1;
}

class UnionFind {
    private int[] parent;
    private int[] rank;
    private int count;  // 连通分量个数

    public UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        count = n;
        for (int i = 0; i < n; i++) {
            parent[i] = i;
        }
    }

    public int find(int x) {
        // 路径压缩
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    public boolean union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX == rootY) return false;
        // 按秩合并
        if (rank[rootX] < rank[rootY]) {
            int temp = rootX;
            rootX = rootY;
            rootY = temp;
        }
        parent[rootY] = rootX;
        if (rank[rootX] == rank[rootY]) {
            rank[rootX]++;
        }
        count--;
        return true;
    }

    public boolean connected(int x, int y) {
        return find(x) == find(y);
    }

    public int getCount() { return count; }
}

// ========== 拓扑排序模板（Kahn算法/BFS） ==========

public int[] topologicalSort(int numCourses, int[][] prerequisites) {
    // 构建邻接表和入度表
    List<List<Integer>> graph = new ArrayList<>();
    int[] inDegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++) {
        graph.add(new ArrayList<>());
    }
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);
        inDegree[pre[0]]++;
    }

    // 将入度为0的节点入队
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++) {
        if (inDegree[i] == 0) queue.add(i);
    }
    int[] order = new int[numCourses];
    int idx = 0;

    while (!queue.isEmpty()) {
        int node = queue.pollFirst();
        order[idx++] = node;
        for (int neighbor : graph.get(node)) {
            inDegree[neighbor]--;
            if (inDegree[neighbor] == 0) {
                queue.add(neighbor);
            }
        }
    }

    return idx == numCourses ? order : new int[0];  // 空数组表示有环
}

class Trie {

        for (char ch : word.toCharArray()) {
            if (!node.children.containsKey(ch)) {
                node.children.put(ch, new TrieNode());
            }
            node = node.children.get(ch);
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        TrieNode node = root;
        for (char ch : word.toCharArray()) {
            if (!node.children.containsKey(ch)) return false;
            node = node.children.get(ch);
        }
        return node.isEnd;
    }

        TrieNode node = root;
        for (char ch : prefix.toCharArray()) {
            if (!node.children.containsKey(ch)) return false;
            node = node.children.get(ch);
        }
        return true;
    }

    class TrieNode {
        Map<Character, TrieNode> children = new HashMap<>();
        boolean isEnd = false;
    }
```

## 9. 回溯算法

### 核心知识点

回溯算法的本质是**穷举所有可能**，通过**剪枝**来减少不必要的搜索。

**回溯通用框架：**
1. 做选择（加入路径）
2. 递归
3. 撤销选择（回溯）

**三种基本模式**：子集、排列、组合

### 模板代码

```java
public List<List<Integer>> backtrackTemplate(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    backtrack(nums, 0, path, result);
    return result;
}

private void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> result) {
    // 结束条件：满足某个条件时收集结果
    if (/* 满足条件 */) {
        result.add(new ArrayList<>(path));   // 注意要拷贝
        return;
    }

    for (int i = start; i < nums.length; i++) {
        // 剪枝（可选）
        if (/* 不满足条件 */) continue;
        path.add(nums[i]);          // 做选择
        backtrack(nums, i + 1, path, result);  // 递归（注意start参数）
        path.remove(path.size() - 1);          // 撤销选择（回溯）
    }
}

// ========== 子集 ==========

public List<List<Integer>> subsets(int[] nums) {

    return result;
}

private void backtrackSubsets(int[] nums, int start, List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path));          // 每个节点都收集（子集问题）
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        backtrackSubsets(nums, i + 1, path, result);
        path.remove(path.size() - 1);
    }
}

public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    boolean[] used = new boolean[nums.length];
    backtrackPermute(nums, used, path, result);
    return result;
}

private void backtrackPermute(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> result) {
    if (path.size() == nums.length) {           // 到达叶子节点
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        // 剪枝：相同元素只在第一次使用时选
        if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;
        used[i] = true;
        path.add(nums[i]);
        backtrackPermute(nums, used, path, result);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}

// ========== 组合 ==========

public List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    backtrackCombine(n, k, 1, path, result);
    return result;
}

private void backtrackCombine(int n, int k, int start, List<Integer> path, List<List<Integer>> result) {
    if (path.size() == k) {                     // 选够k个就收集
        result.add(new ArrayList<>(path));
        return;
    }
    // 剪枝：剩余元素不够选k个了
    for (int i = start; i <= n - k + path.size() + 1; i++) {
        path.add(i);
        backtrackCombine(n, k, i + 1, path, result);
        path.remove(path.size() - 1);
    }
}

// ========== 含重复元素的子集（去重） ==========

public List<List<Integer>> subsetsWithDup(int[] nums) {
    Arrays.sort(nums);                          // 先排序！
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    backtrackSubsetsDup(nums, 0, path, result);
    return result;
}

private void backtrackSubsetsDup(int[] nums, int start, List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path));
    for (int i = start; i < nums.length; i++) {
        // 同一层中跳过重复元素
        if (i > start && nums[i] == nums[i-1]) continue;
        path.add(nums[i]);
        backtrackSubsetsDup(nums, i + 1, path, result);
        path.remove(path.size() - 1);
    }
}
```

## 10. 二分查找

### 核心知识点

二分查找的难点在于**边界条件的处理**。labuladong提出了一套统一模板来解决各种变体。

**核心原则**：
- 搜索区间用 `[left, right]`（闭区间）
- 循环条件用 `left <= right`
- 根据题目要求选择返回 `left`、`right` 或 `mid`

### 模板代码

```java
// 模板1：标准二分查找（找任意一个目标值）
public int binarySearch(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;   // 防止溢出
        if (nums[mid] == target) {
            return mid;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return -1;
}

// 模板2：搜索左边界（第一个等于target的位置）
public int binarySearchLeft(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            right = mid - 1;                    // 收缩右边界，锁定左侧
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    // left是第一个>=target的位置
    if (left < nums.length && nums[left] == target) return left;
    return -1;
}

// 模板3：搜索右边界（最后一个等于target的位置）
public int binarySearchRight(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            left = mid + 1;                     // 收缩左边界，锁定右侧
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    // right是最后一个<=target的位置
    if (right >= 0 && nums[right] == target) return right;
    return -1;
}

// 模板4：寻找第一个满足条件的元素（通用）
public int binarySearchFirstTrue(int n, Predicate<Integer> condition) {
    /*
     * 在 [0, n] 中找到第一个使得 condition(x) 为 True 的 x
     * 假设 condition 具有单调性：False...False True...True
     */
    int left = 0, right = n;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (condition.test(mid)) {
            right = mid;          // mid可能是答案，继续往左找
        } else {
            left = mid + 1;       // mid不是答案，往右找
        }
    }
    return left;
}

// Arrays.binarySearch(a, key) -> 找到返回索引，未找到返回 -(插入点) - 1
```

```java
// 模板1：括号匹配
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> mapping = new HashMap<>();
    mapping.put(')', '(');
    mapping.put(']', '[');
    mapping.put('}', '{');
    for (char c : s.toCharArray()) {
        if (mapping.containsKey(c)) {
            // 遇到右括号，检查栈顶
            char top = stack.isEmpty() ? '#' : stack.pop();
            if (mapping.get(c) != top) return false;
        } else {
            stack.push(c);
        }
    }
    return stack.isEmpty();
}

// 模板2：字符串解码
public String decodeString(String s) {
    Deque<String> strStack = new ArrayDeque<>();
    Deque<Integer> numStack = new ArrayDeque<>();
    StringBuilder currentStr = new StringBuilder();
    int currentNum = 0;

    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            currentNum = currentNum * 10 + (c - '0');
        } else if (c == '[') {
            strStack.push(currentStr.toString());
            numStack.push(currentNum);
            currentStr = new StringBuilder();
            currentNum = 0;
        } else if (c == ']') {
            String prevStr = strStack.pop();
            int num = numStack.pop();
            StringBuilder temp = new StringBuilder(prevStr);
            for (int i = 0; i < num; i++) {
                temp.append(currentStr);
            }
            currentStr = temp;
        } else {
            currentStr.append(c);
        }
    }
    return currentStr.toString();
}

// 模板3：最小栈（辅助栈）
class MinStack {
    private Deque<Integer> stack;
    private Deque<Integer> minStack;   // 辅助栈，栈顶始终是当前最小值

    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        stack.push(val);
        if (minStack.isEmpty() || val <= minStack.peek()) {
            minStack.push(val);
        }
    }

    public void pop() {
        if (stack.pop().equals(minStack.peek())) {
            minStack.pop();
        }
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

```java
    private PriorityQueue<Integer> small; // 最大堆（存较小的一半，用reverseOrder）
    private PriorityQueue<Integer> large; // 最小堆（存较大的一半）

    public MedianFinder() {
        small = new PriorityQueue<>(Collections.reverseOrder());
        large = new PriorityQueue<>();
    }

    public void addNum(int num) {
        // 先加入最大堆
        small.offer(num);
        // 把最大堆的最大值移到最小堆
        large.offer(small.poll());
        // 平衡：最大堆的元素数 >= 最小堆
        if (large.size() > small.size()) {
            small.offer(large.poll());
        }
    }

    public double findMedian() {
        if (small.size() > large.size()) {
            return small.peek();
        }
        return (small.peek() + large.peek()) / 2.0;
    }
}
```

## 13. 贪心算法

### 核心知识点

贪心算法的核心是**每一步都选择局部最优，期望达到全局最优**。

**贪心的关键判断**：贪心选择是否会导致错过全局最优解？如果能证明局部最优一定包含在全局最优中，就可以使用贪心。

### 模板代码

```java
// 模板1：区间贪心（选择不重叠的区间）
public int intervalScheduling(int[][] intervals) {
    // 按结束时间排序
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));
    int count = 0;
    int end = Integer.MIN_VALUE;
    for (int[] interval : intervals) {
        if (interval[0] >= end) {         // 当前区间不与上一个重叠
            count++;
            end = interval[1];
        }
    }
    return count;
}

// 模板2：区间合并
public int[][] mergeIntervals(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));  // 按开始时间排序
    List<int[]> merged = new ArrayList<>();
    merged.add(intervals[0]);
    for (int i = 1; i < intervals.length; i++) {
        int[] last = merged.get(merged.size() - 1);
        if (intervals[i][0] <= last[1]) {     // 有重叠，合并
            last[1] = Math.max(last[1], intervals[i][1]);
        } else {
            merged.add(new int[]{intervals[i][0], intervals[i][1]});
        }
    }
    return merged.toArray(new int[merged.size()][]);
}

    for (int i = 0; i < nums.length; i++) {
        if (i > maxReach) return false;
        maxReach = Math.max(maxReach, i + nums[i]);
    }
    return true;
}
```

```java
// 爬楼梯：dp[i] = dp[i-1] + dp[i-2]
public int climbStairs(int n) {
    if (n <= 2) return n;
    int[] dp = new int[n + 1];
    dp[1] = 1;
    dp[2] = 2;
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];

}

// 空间优化版本

public int uniquePaths(int m, int n) {

    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int j = 0; j < n; j++) dp[0][j] = 1;
    for (int i = 1; i < m; i++) {

// ========== 0-1背包模板 ==========

public int knapsack01(int[] weights, int[] values, int capacity) {
    /*
     * weights: 物品重量列表
     * values: 物品价值列表
     * capacity: 背包容量
     * 每个物品只能选一次
     */
    int[] dp = new int[capacity + 1];   // 一维优化
    for (int i = 0; i < weights.length; i++) {
        // 必须倒序遍历！防止同一物品被重复选取
        for (int w = capacity; w >= weights[i]; w--) {
            dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}

// ========== 完全背包模板 ==========

public int knapsackComplete(int[] weights, int[] values, int capacity) {
    /*
     * 每个物品可以选无限次
     */
    int[] dp = new int[capacity + 1];
    for (int i = 0; i < weights.length; i++) {
        // 正序遍历！允许同一物品被多次选取
        for (int w = weights[i]; w <= capacity; w++) {
            dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }
    return dp[capacity];

// 最长递增子序列（LIS）
public int lengthOfLIS(int[] nums) {
    int[] dp = new int[nums.length];  // dp[i] = 以nums[i]结尾的LIS长度
    Arrays.fill(dp, 1);
    for (int i = 1; i < nums.length; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[i] > nums[j]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
    }
    int maxLen = 0;
    for (int len : dp) maxLen = Math.max(maxLen, len);
    return maxLen;
}

// LIS的O(nlogn)解法（贪心+二分）
public int lengthOfLISFast(int[] nums) {
    List<Integer> tails = new ArrayList<>();  // tails[i] = 长度为i+1的递增子序列的最小末尾
    for (int num : nums) {
        int pos = lowerBound(tails, num);
        if (pos == tails.size()) {
            tails.add(num);
        } else {
            tails.set(pos, num);
        }
    }
    return tails.size();
}

private int lowerBound(List<Integer> list, int target) {
    int left = 0, right = list.size();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (list.get(mid) < target) left = mid + 1;
        else right = mid;
    }
    return left;
}

// 最长公共子序列（LCS）
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i-1) == text2.charAt(j-1)) {
                dp[i][j] = dp[i-1][j-1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
            }
        }
    }
    return dp[m][n];
}

// 编辑距离
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];
    // base case
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i-1) == word2.charAt(j-1)) {
                dp[i][j] = dp[i-1][j-1];
            } else {
                dp[i][j] = 1 + Math.min(dp[i-1][j],       // 删除
                               Math.min(dp[i][j-1],        // 插入
                                        dp[i-1][j-1]));    // 替换
            }
        }
    }
    return dp[m][n];
}
```

#### 荷兰国旗问题（三路划分）

```java
public void sortColors(int[] nums) {
    // 将数组中的0,1,2排序，0在前，1在中，2在后
    int p0 = 0;               // 0的右边界
    int p2 = nums.length - 1; // 2的左边界
    int curr = 0;
    while (curr <= p2) {
        if (nums[curr] == 0) {
            swap(nums, curr, p0);
            p0++;
            curr++;
        } else if (nums[curr] == 2) {
            swap(nums, curr, p2);
            p2--;       // 注意：curr不加1，因为交换过来的数还没检查
        } else {
            curr++;
        }
    }
}

private void swap(int[] nums, int i, int j) {
    int temp = nums[i];
    nums[i] = nums[j];
    nums[j] = temp;
}
```

#### 下一个排列算法

```java
public void nextPermutation(int[] nums) {
    /*
     * 找到下一个字典序更大的排列（原地修改）
     * 步骤：
     * 1. 从右往左找第一个 nums[i] < nums[i+1] 的位置
     * 2. 从右往左找第一个 nums[j] > nums[i] 的位置
     * 3. 交换 nums[i] 和 nums[j]
     * 4. 反转 nums[i+1:] 使其升序
     */
    int n = nums.length;
    int i = n - 2;
    while (i >= 0 && nums[i] >= nums[i + 1]) {
        i--;
    }
    if (i >= 0) {
        int j = n - 1;
        while (nums[j] <= nums[i]) {
            j--;
        }
        swap(nums, i, j);
    }
    // 反转 i+1 到末尾
    int left = i + 1, right = n - 1;
    while (left < right) {
        swap(nums, left, right);
        left++;
        right--;
    }
}
```

```java
public long fastPower(long base, long exp, long mod) {
    long result = 1;
    base %= mod;
    while (exp > 0) {
        if ((exp & 1) == 1) {
            result = (result * base) % mod;
        }
        base = (base * base) % mod;
        exp >>= 1;
    }
    return result;
```
